Instead of **`subscription.listen(…)`** method like above simply return the **`Stream`** in the overridden **`build()`** method of **`StreamNotifier<T>`** (Just like same API of **`AsyncNotifier`** & **`Notifier`**)

No **`StreamSubscription<T>`**, no dispose and no cancel (like above). When our widgets watches **`StreamNotifier`** using **`ref.watch(…)`**, **Riverpod** does this:

```text
subscribe to stream
↓
new Position
↓
update AsyncValue
↓
rebuild widgets
```

When nobody watches anymore, unsubscribe automatically. Instead, manually owning the subscription now **Riverpod** owns it.

Also custom or manual methods can be defined here along with the **`build()`** method and access previous data or current data in manual methods using **`state.value`** (like **`AsyncNotifier`**)

```dart
class LocationNotifier extends StreamNotifier<Position> {
  @override
  Stream<Position> build() {
    return Geolocator.getPositionStream();
  }
  …
}
```

Provider, set **`isAutoDispose:`** to true to automatically cancel the **`StreamSubscription<T>`** when no one is watching:

```dart
final locationProvider =
   StreamNotifierProvider<LocationNotifier, Position>(
     LocationNotifier.new,
     isAutoDispose: true
   );
```

And **`state`** (each value emitted by **`Stream`**) is automatically wrapped by **Riverpod** (like **`AsyncNotifer`**) by **`AsyncValue<Poistion>`** (**`AsyncLoading()`**, **`AsyncData()`**, …). Because Streams can:

- Load
- Emit data
- And throw errors

In the UI, we can listen to the values using **`location.when(…)`** method (exactly like **`AsyncNotifier/FutureProvider`**)

```dart
final location = ref.watch(locationProvider);

return location.when(
  data: (position) => Text(position.latitude.toString()),
  loading: () => CircularProgressIndicator(),
  error: (e, _) => Text(e.toString()),
);
```

## Automatic_Stream_Cancelling

With **`StreamNotifier`**: if the provider is **`isAutoDispose: true`** then **Riverpod** automatically cancels the Stream.

```text
Widget removed
↓
Provider disposed
↓
Subscription cancelled
```

## Transforming_the_Stream_if_Needed

Suppose GPS emits **`Position`** but we only want latitude. Simply transform it.

```dart
@override
Stream<double> build() {
  return Geolocator.getPositionStream()
       .map((position) => position.latitude);
}
```

Now our provider emits

```text
12.23
12.25
12.28
```

If we need filtering like only accurate positions are emitted

```dart
@override
Stream<Position> build() {
  return Geolocator.getPositionStream()
       .where((position) => position.accuracy < 20);
}
```

If we need to combine **`Stream`**’s like GPS stream and Internet stream, we can combine them before returning. **Riverpod** doesn’t care where the stream comes from

```dart
@override
Stream<MyState> build() {
  return someCombinedStream;
}
```

## Manual_Methods_in_StreamNotifier

The biggest advantage over **`StreamProvider`**

```dart
class ChatNotifier extends StreamNotifier<List<Message>> {
  @override
  Stream<List<Message>> build() {
    return repository.messages();
  }
  Future<void> sendMessage(String text) {
    return repository.send(text);
  }
  Future<void> deleteMessage(String id) {
    return repository.delete(id);
  }
}
```
