We’ll create a **`AsyncNotifier`** class that will provide our data (wrapped with **`AsyncValue()`**) and call our API service if the **`movieId`** is new and KEY is not present in the **`Map`** in the Repository Layer.

We are storing the **`MovieDetails`** object in the **`Map`** in the Repository layer with its **`movieId`** as the KEY. So we can easily check using **`.containsKey()`** method (Cache hit or miss)

If data is previously fetched from the API return it to the notifier class or if not call the API and fetch it and then save it in the **`Map`** with its **`movieId`** as KEY

And use **`Provider<T>()`** for Singleton Pattern of the repository so it only points to one instance (doesn’t create new)

```dart
class MovieRepository {
  MovieRepository({required this._apiService}); // DI

  final ApiService _apiService;
  final Map<int, MovieDetailsModel> _cache = {};

  MovieDetailsModel? checkCache(int movieId) {
    if (_cache.containsKey(movieId)) {
      return _cache[movieId];
    }
    return null;
  }

  Future<MovieResult> getMovieDetails(int movieId) async {
    final APIResponse response = await _apiService.getRequest(url: '...');
    if (response.isSuccess) {
      final movieDetails = MovieDetailsModel.fromJson(response.body);
      _cache[movieId] = movieDetails;
      return MovieResult(movieDetailsModel: movieDetails, errorMessage: null);
    }
    return MovieResult(
      movieDetailsModel: null,
      errorMessage:
          'Status Code: ${response.statusCode} Message: ${response.errorMessage}',
    );
  }
}
```

```dart
final movieRepoProvider = Provider<MovieRepository>((ref) {
  final apiService = ref.watch(apiServiceProvider);

  return MovieRepository(apiService: apiService);
});
```

Create a **`MovieResult`** model so we can return both the data and error message to the **`AsyncNotifier`** class and also check if succeeded or not

```dart
class MovieResult {
  final MovieDetailsModel? movieDetailsModel;
  final String? errorMessage;
  MovieResult({this.movieDetailsModel, this.errorMessage});
  bool get isSuccess => movieDetailsModel != null;
}
```

Then **Riverpod**’s **`AsyncNotifier`** class becomes very simple. If data is present in repository cache fetch from there otherwise from the API

Also use Family in **Riverpod** to pass parameters (**`movieId`**) in the **`build()`** method (instead of defining a new manual method). And **`throw Exception(…)`** in the **`build()`** method will automatically handle the error message by wrapping it with **`AsyncError()`** and stopping the method

```dart
class MovieNotifier extends AsyncNotifier<MovieDetailsModel> {
  MovieNotifier(this.movieId);
  final int movieId;

  MovieRepository get _movieRepository => ref.watch(movieRepoProvider);

  @override
  Future<MovieDetailsModel> build() async {
    final cachedData = _movieRepository.checkCache(movieId);
    if (cachedData != null) return cachedData;

    final MovieResult result = await _movieRepository.getMovieDetails(movieId);

    if (!result.isSuccess || result.movieDetailsModel == null) {
      throw Exception(result.errorMessage ?? 'throwing from notifier');
    }

    return result.movieDetailsModel!;
  }
}
```

```dart
final movieDetailsProvider =
   AsyncNotifierProvider.family<MovieNotifier, MovieDetailsModel, int>(
     MovieNotifier.new,
     isAutoDispose: true,
   );
```

Then in the UI use it like this:

```dart
final state = ref.watch(movieDetailsProvider(123));
…
state.when(…)
```

## Industry_Pattern

Most production apps follow this pattern:

```text
UI
↓
AsyncNotifier/ Riverpod
↓
Repository
↓
Remote API
```

With caching inside the repository:

```text
Repository
├─ Memory Cache
├─ Local Database (optional)
└─ Remote API
```

> **NOTE:** For industry projects use repository pattern
