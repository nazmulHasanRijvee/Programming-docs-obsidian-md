There are dispose alternatives in **Riverpod** (just like **`initState`**) that runs when the Provider is disposed (by auto dispose or **`ref.invalidate`**). We can dispose controllers and cancel **`Stream`** listeners here

In old or legacy **`StateNotifier<T>`** class there’s a **`dispose()`** method that we just had to **override** like this to dispose controllers

```dart
class TaskStateNotifier extends StateNotifier<TaskState> {
  TestNotifier() : super(TaskState);
  …
  @override
  void dispose() {
    _controller.dispose();
    _streamSubscription.cancel();
    super.dispose();
  }
}
```

But in **`Notifier<T>`**, **`AsyncNotifier<T>`** and **`StreamNotifier<T>`** modern classes we have **`ref.onDispose()`** callback that runs when Provider is disposed by (auto dispose or **`ref.invalidate`**) in **`build()`** method or any manually defined method. So, we can dispose any controllers or cancel **`Stream`**’s when Provider is disposed (Best Practice dispose once in **`build()`** method)

```dart
class AuthNotifier extends Notifier<bool> {
  final bool isLoading = false;
  StreamSubscription<Uri>? streamSubscription;
  TextEditingController _controller = TextEditingController();

  @override
  bool build() {
    …
    ref.onDispose(() {
      streamSubscription?.cancel();
      _controller.dispose();
    });

    return false;
  }
}
```

Or we can use a helper method (**`_registerDisposeCallbacks`**) to register the clean up or disposing of controllers and **`Stream`**’s in **`build()`**. We can also create the controller in a helper method (**`_createController`**) so that initialization and disposal stay together (Clean Pattern)

```dart
class AuthNotifier extends Notifier<bool> {
  final bool isLoading = false;
  StreamSubscription<Uri>? streamSubscription;
  TextEditingController _controller = TextEditingController();

  @override
  bool build() {
    …
    _registerDisposeCallbacks();
    return false;
  }
  void _registerDisposeCallbacks() {
    ref.onDispose(() {
      streamSubscription?.cancel();
      _controller.dispose();
    });
  }
}
```

**OR**

```dart
…
@override
bool build() {
  …
  _createController();

  return false;
}
void _createController() {
  controller = TextEditingController();
  ref.onDispose(() {
    controller.dispose();
  });
}
```
