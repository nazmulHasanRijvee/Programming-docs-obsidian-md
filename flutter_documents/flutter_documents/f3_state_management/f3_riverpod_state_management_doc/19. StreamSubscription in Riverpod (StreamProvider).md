We can also use **`StreamSubscription<…>`** in **`StateNotifier<…>`** in **Riverpod** because it has **`@override`** **`dispose()`** method so we can listen to the **`Stream`** and cancel it when we want (NOT Recommended).

Alternative, we can also use **`ref.listen()`** and **`StreamNotifier<…>()`**

This **`StateNotifier<…>`** notifier class gets disposed automatically if auto dispose is on. When we create the Provider of this notifier class we have to be use **`.autoDispose<…, …>()`** method

```dart
final locationProvider =
   StateNotifierProvider.autoDispose<LocationNotifier, Position?>(
  (ref) => LocationNotifier(),
);
```

Now when screen is removed **`Stream`** cancels and Notifier disposes. If we don’t do this (NOT RECOMMENDED) we have to manually cancel from UI in dispose method of UI

Values form stream subscription will be updated when **`state`** model is updated or re-assigned.

In UI, we can listen to the changes using **`ref.watch(…)`** method or extending **`ConsumerWidget`**.

**`ChangeNotifier`** inherited class

```dart
class LocationNotifier extends StateNotifier<Position?> {
  LocationNotifier() : super(null) {
    _startListening();
  }
  StreamSubscription<Position>? _subscription;
  void _startListening() {
    _subscription = Geolocator.getPositionStream().listen((position) {
      state = position; // this replaces notifyListeners()
    });
  }
void stopListening() {
  _subscription?.cancel();
}
  @override
  void dispose() {
    _subscription?.cancel();
    super.dispose();
  }
}
```

Provider

```dart
final locationProvider =
   StateNotifierProvider.autoDispose<LocationNotifier, Position?>(
  (ref) => LocationNotifier(),
);
```

In UI if auto dispose is not used

```dart
@override
void dispose() {
  ref.read(LocationNotifier.notifier).stopListening();
  super.dispose();
}
```

## Using_ValueChanged_For_Listening_Stream_Values

**REMEMBER**, Controllers like **`mapController`** or anything doesn’t work with **`ref.watch().value`** instead because **`watch()`** is for UI rendering. we have to use **`ValueChanged<…>`** call back method to listen to values directly from **`StreamSubscription`** from notifier class in UI.

```dart
void listenStream(ValueChanged<…> onChanged) {
  _subscription = _geolocator.getPositionStream().listen((position) {
           …
           onChanged(position);
   });
}
// UI
notifierClass.listenStream( (value) {
           mapController.animateCamera(…)
});
```

## ref.listen()

Or we can use **`ref.listen()`** too. It gives us previous **`state`** model and new **`state`** model too (when **`state`** model is reassigned) which is an extra plus this is why **Riverpod** is superior

**`StateNotifier`**

```dart
class LocationNotifier extends StateNotifier<Position?> {
  StreamSubscription<Position>? _sub;
  LocationNotifier() : super(null);
  void startListening() {
    _sub = Geolocator.getPositionStream().listen((position) {
      state = position; // this triggers ref.watch rebuild
    });
  }
  @override
  void dispose() {
    _sub?.cancel();
    super.dispose();
  }
}
```

Provider

```dart
final locationProvider =
   StateNotifierProvider.autoDispose<LocationNotifier, Position?>(
       (ref) => LocationNotifier());
```

In UI,

```dart
@override
void initState() {
  super.initState();
  // Start location stream
  Future.microtask(() {
    ref.read(locationProvider.notifier).startListening();
  });
  ref.listen(locationProvider, (previous, next) {
    if (next != null) {
      mapController.animateCamera(
        CameraUpdate.newLatLng(
          LatLng(next.latitude, next.longitude),
        ),
      );
    }
  });
}
```
