If we have a **Riverpod** Provider (`taskCardProvider` of **`TaskCardNotifier`**) for a list of **`TaskCard`**’s in **`ListView`**/**`GridView`** and we assign the **`TaskCardProvider`** in `taskCard` then:

- Every **`TaskCard`** that listens to **`TaskCardProvider`** rebuilds when state is reassigned
- Every delete button checks the same state
- As a result, all cards show **`CircularProgressIndicator`** when just deleting one of them

This is expected behavior with a shared **Provider** + global state. Because we’re using per-item UI state (loading for one task) inside a global provider. Mental model:

```text
ListView
 └── ONE TaskCardProvider
      ├── TaskCard A
      ├── TaskCard B
      ├── TaskCard C
```

---
## Solution

To solve this, when creating the **`taskCardProvider`** (a family provider, same **`StateNotifier`**) along with **`ref`** we’ll also pass **`taskId`** as parameter. Each **`taskId`** means new Provider instance (SEE [[11. Family in Riverpod (Parameters in Provider)]])

The in **`ListView`** inside the **`itemBuilder: ref.watch`** the Provider passed with **`taskId`**’s. So, separate Provider instances are created according to the **`taskId`**

In this way, each **`TaskCard`** will have its own **`taskCardProvider`** state to manage instead of sharing a global one

**`.watch`** is for **`ListView`**/**`GridView`** rebuilds based on state changes. Mental model per-item **Provider**:

```text
ListView
├── TaskCardProvider (A)
│    └── TaskCard A
├── TaskCardProvider (B)
│    └── TaskCard B
└── TaskCardProvider (C)
     └── TaskCard C
```

In **Riverpod**, we never create multiple providers manually. We create one provider family and **Riverpod** creates instances for us

Task card state:

```dart
class TaskCardState {
  final bool isDeleting;
  const TaskCardState({this.isDeleting = false});
  TaskCardState copyWith({bool? isDeleting}) {
    return TaskCardState(
      isDeleting: isDeleting ?? this.isDeleting,
    );
  }
}
```

Task card notifier:

```dart
class TaskCardNotifier extends StateNotifier<TaskCardState> {
  TaskCardNotifier() : super(const TaskCardState());
  Future<void> deleteTask(String taskId) async {
    state = state.copyWith(isDeleting: true);

    await Future.delayed(const Duration(seconds: 1)); // API call
    state = state.copyWith(isDeleting: false);
  }
}
```

Create a family Provider:

```dart
final taskCardProvider =
   StateNotifierProvider.family<TaskCardNotifier, TaskCardState, String>(
  (ref, taskId) {
    return TaskCardNotifier();
  },
);
```
