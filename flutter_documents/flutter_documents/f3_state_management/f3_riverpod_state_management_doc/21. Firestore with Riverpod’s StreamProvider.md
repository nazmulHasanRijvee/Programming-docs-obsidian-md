Industry apps almost never use **`StreamBuilder`** directly for complex apps they use **`.when()`** method instead.

This is the mental model:

```text
Firestore Stream
  ↓
StreamProvider
  ↓
AsyncValue<T>
  ↓
UI reacts
```

**`StreamProvider`** with **`QuerySnapshot`** (Collection Listener). Listening to multiple documents means using **`QuerySnapshot`**. This is the Type of our Provider

First, we’ll create our **`StreamProvider<QuerySnapshot>`** (**`userStreamProvider`**), no notifier class is needed. Then we’ll simply consume the Provider in the **`ConsumerWidget`**. Just like repositories in **Riverpod**, directly creating a Provider without notifier.

Use it in the UI like **`AsyncNotifiers .when()`** method

Provider

```dart
final usersStreamProvider =
   StreamProvider<QuerySnapshot>((ref) {
  return FirebaseFirestore.instance
      .collection('users')
      .snapshots();
});
```

UI

```dart

  const UsersPage({super.key});
```

## For_Single_Document

For single document listener just use **`DocumentSnapshot`** as **`StreamProvider`**’s type. **`family`** or **`DocumentSnapshot`** allows dynamic document IDs (**`uid`**) which can be passed like **`ref`**. Then same as before consume the Provider in UI like **`AsyncNotifiers .when()`** method

Provider

```dart
final userStreamProvider =
   StreamProvider.family<DocumentSnapshot, String>((ref, uid) {
  return FirebaseFirestore.instance
      .collection('users')
      .doc(uid)
      .snapshots();
});
```

UI

```dart
class ProfilePage extends ConsumerWidget {
  final String uid;
  const ProfilePage({super.key, required this.uid});
  @override
  Widget build(BuildContext context, WidgetRef ref) {
```

## Real-time_Query_in_Riverpod_(In_Provider)

We can also do real-time Query with filtering when we are creating the **`StremProvider<…>`**

```dart
final activeUsersProvider =
   StreamProvider<QuerySnapshot>((ref) {
  return FirebaseFirestore.instance
      .collection('users')
      .where('isActive', isEqualTo: true)
      .orderBy('lastLogin', descending: true)
      .snapshots();
});
```
