It is similar to **`context.mounted`** but for **`Ref`**. It returns **true** if a **Provider** is still mounted (alive)

This is important when using a **`Ref`** after its **Provider** has been disposed throws an **`UnmountedRefException`** because **`Ref`** is used after an async operation (**`await`**), if the **Provider** was disposed (like rebuilt, or no longer listened) while the asynchronous operation was still pending.

```dart
class TaskList extends Notifier<List<Task>> {

  @override
  List<Todo> build() => [];

  Future<void> addTask(String title) async {
    // Post the new task to the server
    final newTask = await api.addTask(title);

    // Check if the provider is still mounted, after the async operation
    if (!ref.mounted) return;

    // If it is, update the state
    state = [...state, newTodo];
  }
}
```
