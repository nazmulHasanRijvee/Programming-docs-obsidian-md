In **Riverpod**, it’s possible to automatically destroy resources associated with a **Provider** when it is no longer needed

To enable or disable it use `.autoDispose<…>` constructor (LEGACY) or `isAutDispose: true` (RECOMMENDED) property in the **Provider** (In **Rivepod** code generation `@riverpod` it's already on by default)

```dart
final taskProvider = NotifierProvider.autoDispose<TaskNotifier, TaskState>(
    TaskNotifier.new,
);
// OR
final taskProvider = NotifierProvider<TaskNotifier, TaskState>(
  TaskNotifier.new,
  isAutoDispose: true,
);
```

---
## When_Automatic_Disposal_is_Triggered

When it’s enabled, **Riverpod** will track whether a **Provider** has listeners or not. This happens by tracking `ref.watch`/`ref.listen` calls (and a few others).

When that counter reaches zero, the provider is considered "not used", and `ref.onCancel` is triggered. At that point, **Riverpod** waits for one frame (cf. `await null`). If, after that frame, the **Provider** is still not used, then the provider is destroyed and `ref.onDispose` will be triggered.

---
## Reacting_to_state_Disposal_(Disposing_Controllers)

In **Riverpod**, there are a few built-in ways for state to be destroyed like:

- The **Provider** is no longer used and is in "auto dispose" mode. In this case, all associated state with the **Provider** is destroyed.
- The **Provider** is recomputed, such as with `ref.watch()`. In that case, the previous state is disposed, and a new state is created.

In both cases, we may want to execute some logic when that happens. This can be done with `ref.onDispose()`. This method runs whenever the state is destroyed. For example, use it to close any active **`StreamController`**. See ref.onDispose in Riverpod part above

```dart
final provider = StreamProvider<int>((ref) {
  final controller = StreamController<int>();
  // When the state is destroyed, close the StreamController.
  ref.onDispose(controller.close);
  return controller.stream;
});
```

## Manually_Forcing_the_Destruction_of_a_Provider_(using_ref.invalidate)

if we want to force the destruction of a **Provider** use `ref.invalidate()`, which can be called from another **Provider** or a widget (SEE ABOVE)

Also, a **Provider** with specific combination of parameter can be disposed (SEE family)

```dart
void onTap() {
  // Invalidate all possible parameter combinations of this provider.
  ref.invalidate(provider);
  // Invalidate a specific combination only
  ref.invalidate(provider('John'));
}
```

## Fine-tuned_disposal_with_ref.keepAlive

If we want to keep the state of successful network requests, but not cache failed requests.

This can be achieved with `ref.keepAlive()`, after enabling Automatic Disposal. Using it, we can decide when the state or **Provider** stops being automatically disposed.

Here, we keep the **FutureProvider** alive only after the request has successfully completed. If the request failed (and threw an exception) then when **Provider** stops be listened to, the state will be destroyed

Also `link.close()` can be used to restore the auto-dispose behavior

```dart
final provider = FutureProvider.autoDispose<String>((ref) async {
  final response = await http.get(Uri.parse('https://example.com'));
  final link = ref.keepAlive();
  // use it to restore the auto-dispose behavior
  // link.close();

  return response.body;
});
```

## Keeping_state_Alive_for_a_Specific_Amount_of_Time

By using a **`Timer`** + `ref.keepAlive()`, we can keep the state alive for a specific amount of time. To make this logic reusable, we could implement it in an extension method:

```dart
extension CacheForExtension on Ref {
  /// Keeps the provider alive for [duration].
  void cacheFor(Duration duration) {
    // Immediately prevent the state from getting destroyed.
    final link = keepAlive();
    // After duration has elapsed, we re-enable automatic disposal.
    final timer = Timer(duration, link.close);

    // Optional: when the Provider is recomputed (such as with ref.watch),
    // we cancel the pending timer.
    onDispose(timer.cancel);
  }
}
```

Then use it like this:

```dart
final provider = FutureProvider.autoDispose<Object>((ref) async {
  /// Keeps the state alive for 5 minutes
  ref.cacheFor(const Duration(minutes: 5));

  return http.get(Uri.https('example.com'));
});
```

Or if using **`AsyncNotifierProvider`** then call it in the `build()` method of **`AsyncNotifier`**

```dart
class MoviesNotifier extends AsyncNotifier<List<Movie>> {
  @override
  Future<List<Movie>> build() async {
    // Keeps the state alive for 5 minutes
    ref.cacheFor(const Duration(minutes: 5));

    return repository.fetchMovies();
  }
}
```

This logic can be tweaked to fit our needs like destroying the state only if a **Provider** hasn’t been listened to for specific amount of time (like 30 seconds).

For example, Dispose the **Provider** only if nobody listens to it for 30 seconds but if someone starts listening to it for 30 seconds then cancel the disposal. For this we could use:

- `ref.onCancel()`  Called when the last listener (`ref.watch`/`ref.listen`) stops watching the **Provider**
- `ref.onResume()`  Called when a new listener (`ref.watch`…) starts watching the **Provider** again before the **Provider** is disposed

Here’s a small extension using `ref.onCancel` and `ref.onResume`

```dart
extension CacheWhileUnused on Ref {
  void cacheWhileUnused(Duration duration) {
    final link = keepAlive();
    Timer? timer;

    // Last listener removed
    onCancel(() {
      timer = Timer(duration, link.close);
    });

    // A listener came back
    onResume(() {
      timer?.cancel();
      timer = null;
    });

    // Provider is actually disposed
    onDispose(() {
      timer?.cancel();
    });
  }
}
```

Then use it like this:

```dart
final moviesProvider = FutureProvider<List<Movie>>(
  isAutoDispose: true,
  (ref) async {
    ref.cacheWhileUnused(const Duration(seconds: 30));
    return repository.fetchMovies();
  },
);
```

Or if using **`AsyncNotifierProvider`** then call it in the `build()` method of **`AsyncNotifier`**

```dart
class MoviesNotifier extends AsyncNotifier<List<Movie>> {
  @override
  Future<List<Movie>> build() async {
    ref.cacheWhileUnused(const Duration(seconds: 30));

    return repository.fetchMovies();
  }
}
```
