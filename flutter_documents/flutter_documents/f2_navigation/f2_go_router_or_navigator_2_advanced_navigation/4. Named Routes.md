Instead of navigating by raw path string, a **`GoRoute()`** can carry a **`name:`** parameter which is a unique identifier we can reference from anywhere in the app instead of the literal **`path:`**.

```dart
// ...
GoRoute(
  name: 'song',
  path: 'songs/:songId',
  builder: // ...,
),

// Usage
context.goNamed('song', pathParameters: {'songId': '123'});
```

---
## Why_Use_It

Every **`context.go('/songs/123')`** call we write is a raw string the compiler can't check. If someone renames the path to **`'/music/:songId'`** later, every hardcoded **`'/songs/...'`** call site silently breaks. **Dart** won't flag it, it fails at runtime.

With path navigation we have to manually construct the URL to pass Path params at the call site:

```dart
context.go('/users/$userId');
```

But with Named navigation we have to only specify the **`name:`** and pass the Path params. **`GoRouter()`** constructs the URL for us, it says "I want the **`user`** route, and here its **`userId`**"

```dart
context.goNamed(
  "user",
  pathParameters: {
    "userId" : userId.toString()
  }
)
```

> **NOTE:** In industry-standard an **`enum Routes {...}`** is used as a replacement of static const variables for centralization and assigned to **`GoRoute()`** as **`Routes.login.name`**, **`Routes.login,path`**

```dart
enum Routes {
  splash("/"),
  login("/login"),
  home("/home"),
  
  const Routes(this.path);
  final String path;
}
```

---
## Basic_Usage

**`name:`** (of **`GoRoute()`**) -> registers a unique identifier for that route

**`context.goNamed(name, pathParameters:, queryParameters:)`** -> `.go()` but resolved by name instead of raw path

**`context.pushNamed(name, ...)`** -> **`push()`**, resolved by name

**`context.namedLocation(name, pathParameters:)`** -> Returns a concrete path **String** of a name, without navigating. Useful when we need the location itself (e.g. inside **`redirect`**)

**`pathParameters:`** **Map** is just addressed by **`name`** instead of a path string at the call site.

```dart
// ...
GoRoute(
  name: 'userProfile',
  path: 'users/:userId',
  builder: (context, state) {
    final userId = state.pathParameters['userId']!;
    return UserProfileScreen(userId: userId);
  },
),

// Usage
onPressed: () =>
  context.goNamed( 'userProfile', pathParameters: {'userId': '42'}, ),
```

---
## Important_Concepts

**`namedLocation`** is for when we need the path, not navigation itself. The clearest case is inside **`redirect`** (SEE Module 6 preview), where we return a location string, not calling **`go()`** directly:

```dart
redirect: (BuildContext context, GoRouterState state) {
  if (!AuthState.of(context).isSignedIn) {
    return context.namedLocation('signIn');
  }
  return null;
},
```

---
## Common_Mistakes

Names must be unique across the entire Router Tree, not just among siblings. Two `GoRoute()`s anywhere in our app can't share a same **`name:`**, even if nested in unrelated branches.
