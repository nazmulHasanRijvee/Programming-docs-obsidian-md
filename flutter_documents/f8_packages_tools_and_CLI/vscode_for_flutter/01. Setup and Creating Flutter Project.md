Open vs code go to extensions and install **Flutter**, **Dart**, Kotlin by Jetbrains (for build.gradle.kts), XML by redhat  extensions

## Create a Flutter Project:
simply go to the view tab in vs code on the top left corner and click on it. Go to:
- **View** > **Command Pallet**  then type **`>Flutter:`** (All **Flutter** and **Dart** commands are present here)
- And click on **Create New Project,** then click on Application or Empty Application (Or module or package or plugin)
- Then create a folder to contain our project files (which will not be the app name or app ID in this case)
- Then type the name of the **Flutter** project which will be our app name (like **android:label=** in **AndroidManifest.xml** and **pubsec.yaml** or package name or app ID too, like **com.example.testing_flutter**)
- After that select platforms for this project like (applicable for Android, iOS, web etc.)
- Then wait for a bit VS code will execute a script of commands like **flutter create** to create our project
