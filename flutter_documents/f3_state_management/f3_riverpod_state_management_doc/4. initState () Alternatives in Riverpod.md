
 \# We can also do something like **initState** in the notifier using curly braces **{}** after constructor like this (Basically calling parent classes constructor using **super(){}** and using it). This calls when Provider is first read or watched **ref.watch/read(provider)** (not runs when **provider.notifier** it’s for accessing notifier class and calling methods). `_init` method is the **initState** of this notifier

```dart
class WeatherProvider extends StateNotifier<WeatherState> {
  WeatherProvider() : super(WeatherState()) {
    _init();
  }
  
  Future<void> _init() async {
    final  coordinates = await getCoordinates(city: 'Dhaka');
    await getWeatherData(coordinates);
  }
}
```

```dart
class TaskAsyncNotifier extends AsyncNotifier<List<TaskModel>> {
```

\# Using **FutureProvider** in here we just call the API like in **initState** before returning the parsed model/data from API for creating the Provider but it’s for just simple one-of fetch

```dart
final weatherProvider = FutureProvider<String>((ref) async {
   // API Simulation
   await Future.delayed(const Duration(seconds: 2));
   return "Sunny";
});

// In our UI
final weatherAsync = ref.watch(weatherProvider);
//…
return weatherAsync.when(
  data: (data) => Text(data),
  loading: () => CircularProgressIndicator(),
  error: (err, stack) => Text('Error: $err'),
);
```
