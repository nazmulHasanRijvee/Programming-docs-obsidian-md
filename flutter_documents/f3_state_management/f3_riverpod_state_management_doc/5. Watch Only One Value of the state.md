 
\# Instead rebuilding widgets when the state models any value is changed. We can watch only one value of the state model and if that changes than the widget gets rebuild (like **ValueNotifier**)

\# Our **Flutter** app might be slow because we are watching too much (**state** and it can cause unnecessary rebuilds (like **User** **state** model’s phone number updates every widget watching this state gets rebuild including the **Text()** widget which only shows user name which is not changed, so it’s an extra rebuild)

\# Mental model, **.watch(provider)** → subscribe to everything but **.watch(provider.select(x))** → subscribe to exactly x value

\# Wrong approach rebuilds when any field changes:

```dart
final  user  =  ref.watch(userProvider);
Text(‘user.name’);
```

\# Correct approach, subscribe to exactly what we need and where we need it:

```dart
final  user  =  ref.watch(userProvider.select((u) => u.name));
Text(‘user.name’);
```
