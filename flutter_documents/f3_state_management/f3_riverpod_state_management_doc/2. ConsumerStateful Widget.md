
\# Using **ConsumerStatefulWidget** in this way we don’t need **WidgetRef ref** as parameter in **build()** method. It becomes available globally like in **build()** method, lifecycle methods (**initState**, **dispose**, **didUpdateWidget**, …), and manually defined helper methods (`_onTap()` or **fetcthData()**) because **ref** is a property of **ConsumerState**

\# If we only need **initState** to fetch data or initialize a provider, we can often avoid the **StatefulWidget** entirely by using a **FutureProvider** or an **AsyncNotifier**. These allow us to handle initialization logic inside the provider itself rather than in the UI lifecycle. But if we have **controllers** like **TextEditingController** and more that needs disposing use **ConsumerStatefulWidget**
