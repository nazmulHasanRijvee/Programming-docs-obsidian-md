#### Definition:
\# `AsyncNotifier<T>` manages its three states automatically. `AsyncValue<T>` like (if want to set the **state** manually):

##### 1. loading:
\# **state = const AsyncLoading()** or **AsyncValue.loading()** to notify the UI immediately to show anything in the **loading:** of **when()**

##### 2. data:
\# **state = const AsyncData** or **AsyncValue.data()** to notify the UI immediately to show anything in the **data:** of **when()**

##### 3. error:
\# **state = const AsyncError()** or **AsyncValue.error()** to notify the UI to show anything in the **error:** (SEE BELOW)

---

#### Mental_Model:
\# Think of **AsyncValue** as a wrapper around our real data. Our job is only to provide the `List<TaskModel>`. **Riverpod** wraps it with the appropriate loading or error state.

```ASCII
AsyncValue<List<TaskModel>>
├── Loading
├── Error
└── Data(List<TaskModel>)
```

#### Basic_Syntax:
\# So, we do NOT need **ApiState enum** (**isLoading**, …) and try/catch in UI. **Riverpod** does it for us through **AsyncValue.** Our state becomes just data so we don’t need a **TaskState** model for type of the notifier we just need data (`List<TaskModel>`) for the type

\# **APICaller** same as before without try/catch. We’ll do **Providers** wiring with the DI (Dependency injection)

\# Create a **AsyncNotifier** and **override** its **build()** method to call automatically when Provider is first read or created (**ref.watch** or **ref.read**) and returns our data after API call and we’ll create one method for manual refresh too that we’ll also return our data after API call and assigned to **state** to notify the listeners (See Below)

\# IMPORTANT, **build()** method runs again when **ref.invalidate()** + **ref.watch()** (see below) or when an **autoDispose** Provider is rebuilt

\# Make sure to add **throw Exception(…)** in **else** block if API request fails this will redirect us to **error:** branch in UI (Returning empty **List** or **null** won’t work and we have to handle that in UI) .We’ll declare the **Provider** too for the notifier

\# Finally, in UI use **taskAsync.when(…)** and properties like `loading: () =>`, `error: (err, _) =>` and `data: (tasks) =>` for loading state, error state and to show data after success

\# Mental model:
- **Notifier** → when state is simple sync
- **AsyncNotifier** → when state depends on async data

\# For APIs **AsyncNotifier** wins 90% of the time. Once we’re comfortable with this, we’ll almost never go back to manual **ApiState**

\# **APICaller** example:

```dart
class ApiCaller {
  ApiCaller(this.getToken);
  final String? Function() getToken;
  final Logger _logger = Logger();
  
  /// Not required try/catch here 
  Future<APIResponse> getRequest ({required String url}) async {
      Uri uri = Uri.parse(url);
      
      _logRequest(url);
      
      Response response = await get(uri, headers: {
        'token' : _tokenSource.accessToken ?? ''
      });
      
      _logResponse(url, response);
      
      final int statusCode = response.statusCode;
      
      if (statusCode == 200) {
        final decodedData = jsonDecode(response.body);
        
        return APIResponse(
            body: decodedData, responseCode: statusCode, isSuccess: true
        );
        
      } else if (response.statusCode == 401){
        await moveToLogin();
        
        return APIResponse(
            body: jsonDecode(response.body), responseCode: statusCode, isSuccess: false, errorMessage: 'Unauthorized'
        );
        
      } else {
        final decodedData = jsonDecode(response.body);
        
        return APIResponse(
            body: decodedData, responseCode: statusCode, isSuccess: false
        );
      }
   // ... 
}
```

\# **AsyncNotifier**, here setting **state = const AsyncLoading()** immediately notifies listeners so the UI can display a loading indicator while the refresh is in progress

\# **AsyncValue.guard()** automatically converts a successful result into **AsyncData()** and any thrown exception or error into **AsyncError()**, so we don’t need our own try/catch block or assigning **state**

```dart
class TaskAsyncNotifier extends AsyncNotifier<List<TaskModel>> {\

  @override
  Future<List<TaskModel>> build() async {
    // called automatically when provider is first read
    final api = ref.read(apiCallerProvider);
    final APIResponse response = await api.getRequest(url:url);
    List<TaskModel> taskList = [];  
    
    if (response.isSuccess) {
      for(Map<String, dynamic> item in response.body['data']){
        taskList.add(TaskModel.fromJson(item));
      }
      
      return taskList;
    } else {
     ///Error logic here
     throw Exception(‘Failed to load tasks’);
     }
  }

  /// Manual refresh
  Future<void> refreshTasks() async {
    state = const AsyncLoading();
    
    state = await AsyncValue.guard(() async {
      final api = ref.read(apiCallerProvider);
      final APIResponse response = await api.getRequest(url:url);
      List<TaskModel> taskList = [];
      
      if(response.isSuccess){  
        for(Map<String, dynamic> item in response.body['data']){  
          taskList.add(TaskModel.fromJson(item));  
        }
        
        return taskList;
     } else {
     ///Error logic here
     throw Exception(‘Failed to load tasks’);
     }
    }); // AsyncValue.guard
    
  }
}
```


\# Provider of async notifier:

```dart
final taskAsyncProvider =
  AsyncNotifierProvider<TaskAsyncNotifier, List<TaskModel>>(
    TaskAsyncNotifier.new,
 );
```


\#  In the UI, use it through **.when(…)** method (Recommended) but if we only need a simple value then we can also use **ref.watch(…).value** (**state.value**) of the **AsyncNotifier** that will give us **null** or value based on the async call (SEE BELOW in **state.value**)

\# UI usage:

```dart
class TaskScreen extends ConsumerWidget {
  const TaskScreen({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final taskAsync = ref.watch(taskAsyncProvider);
    
    return Scaffold(
      body: taskAsync.when(
        loading: () => const Center(
          child: CircularProgressIndicator(),
        ),
        
        error: (err, _) => Center(
          child: Text(err.toString()),
        ),

        data: (tasks) => ListView.builder(
          itemCount: tasks.length,
          itemBuilder: (_, i) => Text(tasks[i].title),
        ),
      ),

      floatingActionButton: FloatingActionButton(
        onPressed: () {
          ref.read(taskAsyncProvider.notifier).refreshTasks();
        },
        child: const Icon(Icons.refresh),
      ),
    );
  }
}
```
