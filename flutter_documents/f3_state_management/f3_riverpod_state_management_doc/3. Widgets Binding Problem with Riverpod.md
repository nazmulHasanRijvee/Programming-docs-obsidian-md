
\# **(Very Important)** When we are calling normal-methods (**String**, **void**)/**async**-methods (**await getCoordinates** for API call) for the first time from the notifier in a method (**fetchWeather**) which is in UI’s **initState** and plus we’re changing something of the state’s property (**isLoading**) which controls the UI, it’s going to show a bug (UI won’t update anymore **Riverpod** breaks)

\# This happens because when we are changing the **state**:

- **ref.watch(weatherProvider)** has NOT run yet and UI does not observe until **ref.watch** runs

- No widget is subscribed

- The **state** changes but is not observed

- **Riverpod** does not replay intermediate state changes. This is the CORE RULE we hit **state** changes before the first **ref.watch** runs, those changes are effectively invisible

\# This is why it feels like the code “stops”. This is a lifecycle ordering issue. To fix this:

- When we change state in **initState** wrap the method (**fetchWeather(…)**) with `WidgetsBinding.instance.addPostFrameCallback((_) {…}`

- Or use manual setter methods (**setLoading()**) in notifier to change the state in **fetchWeather(…)** not in the notifiers methods

- Or use similar to **initState** methods in the notifier initial fetch into the provider, **AsyncNotifier** and **FutureProvider** shown below

\# Don’t do this in notifier without adding **WidgetsBinding…** in the **initState** in UI:

```dart
Future<…> getCoordinates (…) {
	state = state.copyWith(isLoading: true);
	…
	state = state.copyWith(isLoading: false);
}
```

\# Correct Code:

```dart
@override
  void initState() {
    super.initState();
    …
    WidgetsBinding.instance.addPostFrameCallback((_) {
      fetchWeather('Dhaka');
    });
  }

/// In notifier
Future<…> getCoordinates (…) {
   state = state.copyWith(isLoading: true);
   …
   state = state.copyWith(isLoading: false);
}

/// Or use helper methods from notifier and use in or before fetchWeather
void setLoading () { state = state.copyWith(isLoading: true);}
Future<void> onPressed (…) {
   final weather = ref.read(weatherProvider);
   weather.setLoading();
   await fetchWeather(…);
}
```
