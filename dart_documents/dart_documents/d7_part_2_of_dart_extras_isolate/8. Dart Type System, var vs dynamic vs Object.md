**Dart Type System**, **`var`** vs **`dynamic`** vs **`Object`**:

| **`var`**<br><br>**(Inferred & Locked)**                                                                                 | **`dynamic`**<br><br>**(Flexible & Risky)**                                                                                                  | **`Object`**<br><br>**(The Universal Parent)**                                                              |
| ------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Type is determined at compile-time (inferred from value)                                                                 | Type is determined at runtime (Can change freely)                                                                                            | Type is determined at compile time (as generic ‘Object’)                                                    |
| **`var  x  =  ‘Hi’;`**<br><br>**`x  =  123;`** **❌ Error**<br><br>Safe because type is locked. Full compile-time checks. | **`var  y  =  "Hi";`**<br><br>**`y  =  123;`** **✅OK**<br><br>**`y.fool();`** **💥Crash**<br><br>Not safe because run-time errors can happen | **`Object  z  =   "Hi";`**<br><br>**`z.toUpperCase();`** **❌Error**<br><br>Type-safe, but access is limited |
| **Usage:** Direct, safe access to methods                                                                                | **Usage:** ‘Wild’ access. No compiler help                                                                                                   | **Usage:** Must CAST (e.g., **`as String`’**) to use specific methods                                       |

> **NOTE:** Pro-tip, Prefer **`var`** for locals. Use **`Object`** for unknown data. Avoid **`dynamic`** to prevent runtime crashes.
