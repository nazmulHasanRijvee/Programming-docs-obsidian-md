See below [[3. Isloate.run()]] (next topic)

An **`Isolate`** is **Dart’s** unit of concurrency like a Thread but with no shared memory. Each isolate has its own memory heap and Event Loop.

To communicate, Isolates pass messages (serialized) via ports. The Flutter UI runs on the main Isolate. Heavy CPU work on the main isolate = UI jank. Use manual Isolate for advanced control (long-running background jobs, bidirectional messaging).

**`compute()`** spawns a temporary Isolate, runs a top-level (or static) function with a single message, returns the result when done.

Rules for **`compute()`**:

- The function we pass must be a top-level or static function (not an instance or closure).
- The single message argument and the return value must be send-able across Isolates (basic types, Lists/Maps of send-ables, etc.). No direct Dart objects that hold native resources or closures.
- **`compute()`** returns a **`Future<T>`** await it.

Simple compute example. Top-level function must be outside any classes and main() has to be async function for awaiting the Isolate result using compute(). compute() returns the object which is returned by the top-level function it takes (heavyComputation(…)).

```dart
import 'package:flutter/foundation.dart';
int heavyComputation(int n) {
  var sum = 0;
  for (var i = 0; i < n; i++) {
    sum += i;
  }
  return sum;
}
void main () async {
final result = await compute(heavyComputation, 100000000);
print(result);
}
```

- Error: Invalid arguments: we passed a non-send able object → Fix: pass primitive Map/List only.
- Error: compute can't find function → Fix: function must be top-level or static (not inside a class).

## Manual_Isolates_advanced

Use manual isolates when we need:

- Long-lived background worker
- Bidirectional messaging
- Streaming results back progressively

When NOT to use manual isolates

- For simple parsing tasks where compute() does the job.
- If data is tiny isolate overhead may outweigh benefit.

What can/can’t be sent between isolates

- Allowed: primitive types, Lists/Maps of allowed types, Uint8List, simple typed (String, int) data.
- Not allowed: open file handles, complex objects with native resources, closures, BuildContext, State objects. These will throw serialization errors.

```dart
// top-level entry
void isolateEntry(SendPort sendPort) {
  final port = ReceivePort();
  
  sendPort.send(port.sendPort); // send back the port for messages
  
  port.listen((message) {
    final data = message[0];
    final SendPort replyTo = message[1];
    
    // do heavy work
    final result = heavyParse(data); // top-level function
    replyTo.send(result);
  });
}

// main isolate usage
Future<dynamic> runInIsolate(dynamic input) async {
  final receivePort = ReceivePort();
  
  await Isolate.spawn(isolateEntry, receivePort.sendPort);
  
  // first message from isolate is its SendPort
  final sendPort = await receivePort.first as SendPort;
  final responsePort = ReceivePort();
  
  sendPort.send([input, responsePort.sendPort]);
  final result = await responsePort.first;
  
  receivePort.close();
  responsePort.close();
  
  return result;
}
```
