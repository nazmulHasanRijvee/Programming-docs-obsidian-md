It’s a type safe general purpose programming language. It was intended to be an alternative to **JavaScript** by shipping its own virtual machine (**Dart VM**) to run apps in the browser.

It can compile to multiple targets like:

- Native ARM64 machine code (For android and iOS)
- **JavaScript**/**WebAssembly** (**`dart2js`**/**`dart2wasm`** compiler converts **Dart** code -> **JS**/**WASM** code) for web browsers
- And **`X86_64`** (self-contained executables for Windows, Mac OS and Linux)

---
## Compiler

**Dart** has **JIT** (Just in Time compiler) that complies the code on the go like translating a language while speaking. Used for hot reload and restart

And **AOT** (Ahead of Time compiler) that compiles the whole codebase at once like translating the whole book before publishing it (faster at runtime). Used for building release APKs and App Bundle

---
## Isolate_and_Event_Loop

All **Dart** code runs inside of an Isolate which is like a chunk of memory running a single-threaded Event Loop.

This makes it possible to perform asynchronous background work on a single thread. But we can also spawn multiple Isolates to run code in parallel

---
## Functions_and_OOP_in_Dart

Unlike C’s **`main()`** function, **Dart**’s **`main()`** function has no return values so it’s always **`void`**

Every value or anything we can store in a variable is an object in **Dart**, meaning except **`null`** everything in **Dart** is an object

Functions are also first-class objects in **Dart** which means they can be passed around for Functional Programming (**`VoidCallback`**, **`ValueChanged<T>`**, and **lambda functions `() =>`**)
