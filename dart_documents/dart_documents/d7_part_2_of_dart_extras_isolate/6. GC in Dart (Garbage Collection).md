The **Dart VM** (Virtual Machine, a runtime environment and compilation engine for executing **Dart** code) handles memory management using a highly optimized generational garbage collector designed specifically to keep UI-heavy apps running smoothly.

**Dart**'s garbage collection is broken down into two main phases:

- **Young Space (Nursery):** Newly created objects (like temporary widgets) are stored here. It is collected very quickly using a fast, stop-the-world process called a scavenger.
- **Old Space:** Objects that survive a few collection cycles are moved here. This area handles longer-lived objects and is collected concurrently using mark-and-sweep or compacting algorithms so it doesn't freeze our app.
