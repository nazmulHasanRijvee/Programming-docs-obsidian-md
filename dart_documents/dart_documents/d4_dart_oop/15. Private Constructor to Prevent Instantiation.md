**`AppColors._()`** this is called a private constructor. Two things are happening here:

- The underscore makes it private to the file. So, this constructor cannot be accessed outside the file.
- No public constructor exists.

Since **Dart** automatically creates a default constructor only if we don't define one, once we define this private one, the default public constructor disappears.

**`AppColors`** class acts like a folder that stores colors, just access them directly using static. This prevents teammates to create an object of **`AppColors`** class needlessly.

```dart
class AppColors {
  AppColors._();
  
  static …
  // …
}
```

So now this becomes impossible:

```dart
AppColors colors = AppColors(); // ❌ Error
```

Because the only constructor is this, which is private:

```dart
AppColors._();
```
