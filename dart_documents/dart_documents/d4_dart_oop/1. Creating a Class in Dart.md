We can declare variables or properties, method or functions in the class.

Creating an instance or object of a class by using this syntax:

```text
class_name   object_name   =   class_name();
```

we can access the variables/properties or call the method/function of the class using the dot (**.**) after object/instance.

```dart
class Student {
  late String studentName;
  late int age;
  late String address;

  void displayInfo() {
    print('Name: $studentName, Age: $age, Grade: $address');
  }
}

void main () {
  Student student1 = Student();
  print(student1);

  student1.studentName = 'John Doe';
  student1.age = 20;
  student1.address = 'Dhaka';

  print('Name: ${student1.studentName}');

  student1.displayInfo();
}
```
