Abstract class that serves as a blueprint for other classes. It cannot be instantiated directly and must be implemented or extended by subclasses/object. Subclasses must implement/**`@override`** any abstract methods defined here.

It will throw error because we cannot create an instance of an abstract class:

```dart
Animal  animal  = Animal(name: 'Lion');
```

Abstract method must be implemented by subclasses. We have to write this method, otherwise **Dart** will show error if we don't.

```dart
abstract class Animal {
  Animal({required this.name});
  
  String name;
  static String className = 'Animal';

  void eat() {
    print('$name is eating');
  }
  
  void makeSound();
  static void test() {
    print('test');
  }
}

class Dog extends Animal {
  Dog({required super.name, required this.color});
  
  String color;

  @override
  void makeSound() {
    print('$name says Woof Woof');
  }
}

void main () {
  Dog dog = Dog(name: 'Tom', color: 'Black');
  dog.eat();
}
```
