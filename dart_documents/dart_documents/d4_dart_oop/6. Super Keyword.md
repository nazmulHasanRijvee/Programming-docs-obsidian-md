**`super`** keyword is used to access:

- The property (**`super.name`**, **`super.house`** and **`super.land`**)

```dart
class Son extends Father {
  super.name = ‘John’;
}
```

- Or call the methods (**`super.inComeSource()`**) of the parent class.

```dart
class Son extends Father {
  void showIncome() {
    super.incomeSource(); // Calling parent method
  }
}

void main() {
  Son sonObj = Son();
  
  sonObj.showIncome();
}
```

Or call the constructor using **`super()`** method (**`Son(String name) : super(name)`**) of the parent class which is **Father** class here. And we can use parents constructor (**`Father(…)`** as **`super(…)`**) on the right side of `:` and child’s constructor (**`Son(…)`**) on the left side of `:` which will pass the value for parents constructor.

```dart
class Father {
  Father(this.name);
  String name;
}

class Son extends Father {
  Son({String name}) : super(name); /// Calling parent constructor
  /// Another approach
  // Son({required super.name});
}

void main() {
  Son sonObj = Son(name: "John");
}
```
