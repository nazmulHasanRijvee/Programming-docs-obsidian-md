We can create a Class which will have a specific generic type **T**, meaning it can be any type (**`int`**, **`bool`**, **`String`** and **`double`**) but once a type is assigned it won’t take another type.

We can do this by simply adding **`<T>`** after class name in Class declaration. Just add **T** before the things we need the type to be like this **`T method_name`** or **`List<T>`**.

When creating the object specify the class type like this **`class_name<int>`** before the object as object’s type or **`class_name<int>()`** after the object. If we don’t specify it will be **`dynamic`** or **`var`** type

```dart
class Stack<T> {
  final List<T> _elements = [];

  void push(T element) {
    _elements.add(element);
  }
 // …
}

void main () {
  final Stack<int> stack = Stack();

  // Or final stack = Stack<int>();
}
```
