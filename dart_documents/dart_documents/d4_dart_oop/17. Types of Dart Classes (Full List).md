## 2_Abstract_Class

An abstract class is an incomplete class that acts like a blueprint. Key points:

- We can’t create its object directly (have to inherit it)
- Used as parent/base class
- Child class must implement (or override) defined methods
- Used for abstraction, repository patter and specifying rules

```dart
abstract class Animal {
  void sound();
}

class Dog extends Animal {
 @override
 void sound(){
    print(‘Bark’);
 }
}
```

---
## 3_Interface_Class

An interface class is contract that forces another class to override or implement the defined methods using **`implements`** keyword. Key points:

- All methods must override
- Only the interface or implemented methods of the implemented class can be passed to another class as a parameter without passing the other things in the class
- Clean architecture, Repository layer and Dependency injection

```dart
abstract interface class Vehicle {
   void start ();
}
class Car implements Vehicle {
  @override
  void start () {
    print(‘Car Started’);
  }
}
```

## 4_Base_Class

A base class controls inheritance and restricts extension behavior. Like the inherited class has to be final, base or sealed class. Key points:

- Safer inheritance
- Protects architecture
- Controlled extension
- Framework classes, Recure parent classes

```dart
base class Animal {
  void eat() {
      print("Eating");
  }
}

final class Cat extends Animal {
 @override
 void eat() {
   print("The cat is eating");
 }
}
```

---
## 5_Final_Class

A final class cannot be extended or inherited. Key points:

- Stops inheritance
- Improves security
- Prevents unwanted modification
- Secure services, Fixed behavior classes

```dart
final class DatabaseService {
 //Cannot be extended
}
```

---
## 6_Sealed_Class

A sealed class restricts which classes can inherit from it. Key points:

- Child classes must be in same file
- Mostly used in state management
- Great for BLOC states, Events, API states
- Improves type safety
- states, Events, API states

```dart
sealed class AuthState {}
class Loading extends AuthState {}
class Success extends AuthState {}
class Error extends AuthState {}
```

## 7_Mixing_Class

A mixin is used to reuse code in multiple classes without inheritance (**`extends`**). Key points:

- Uses **`with`** keyword
- Reusable methods avoid code duplication
- Multiple classes can use same mixin
- Logger, Validation, Animation and Common helpers

```dart
mixin Logger {
   void log(String message) {
      print(message);
   }
}
class ApiService with Logger {}
class AuthService with Logger {}
```

## 8_Extension_Class

An **`extension`** adds new functionality or method to an existing class. Used in **`BuildContext`** helpers, String formatting, Validation, Navigation shortcuts.

```dart
extension StringExtension as String {
  String capitalize () {
     return this[0].toUpperCase() + subString(1);
  }
}
// Usage
print("nazmul".capitalize());
```

## 9_Generic_Class

A generic class works with multiple specified data types safely. Uses `<T>` and useful for API responses, common models and repositories.

```dart
class APIResponse<T> {
  final T data;
  APIResponse(this.data);
}
// Usage
final response = APIResponse<String>("Flutter");
final response2 = APIRespnse<int>(200);
```

> **NOTE:** There can be generic functions or methods to like this `call<T>(){}`.

## 10_Singleton_Class

A Singleton class creates only one object for the entire app. Key points:

- Saves memory
- Shared globally
- Common in services like Dio service, API service, Database service

```dart
class ApiService {
  ApiService._internal();
 static final ApiService _instance = ApiService._internal();
 factory ApiService() {
   return _instance;
 }
```

## 11_Immutable_Class

Just a class with final fields.

```dart
class User {
  final String name;
  final int age;
  const User(this.name, this.age);
}
```

## 12_Enum_Class

An **`enum`** stores a fixed set of constant values. Use for loading states, API status and theme modes.

```dart
enum Status {
  isLoading,
  success,
  error
}
// Usage
final Status apiStatus = Status.isLoading;
```
