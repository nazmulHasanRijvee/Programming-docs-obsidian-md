The colon **`:`** after the constructor simply does extra work after the constructor is called. Like the **`{}`** second parentheses short hand for single line. Useful to assign values to encapsulated variables like:

```dart
class MovieProvider extends ChangeNotifier{
  MovieProvider({required Repository repository})
    : _repository = repository;

  final Repository _repository;
  // …
```

But starting from **Dart 3.12+** it’s useless we can directly access encapsulated value in constructor like this and it gives us a auto generated named parameter (**`name:`** for **`_name`**):

```dart
class User {
  User({required this._name});
  final String _name;
}
```
