**`this`** keyword in a class (**StorageService**) represents that class (**StorageService**) itself. So, **`this.token`** means **`StorageService.token`**. And **`return this`** means returning self or the class itself (**`StorageService()`**) object itself (like Python’s **self**).

```dart
class StorageService {
  late SharedPreferences _prefs;
  
  Future<StorageService> init() async {
    _prefs = await SharedPreferences.getInstance();
    return this; // return self (StorageService)
  }
// …
}

// Usage
final storageService = StorageService.init();
```

Also **`this.token`** keyword is used refer to the current classes property if we have duplicate variables (**token** parameter in a method).

## copyWith_method_using_this_Keyword

To update an object while keeping its unchanged properties, use the **`copyWith()`** method.

**`copyWith()`** creates a new object of the same class, applying any provided values while keeping old ones if parameters are **`null`**.

Since parameters are optional, only the ones we pass will overwrite existing values.

**`this`** keyword refers to the current object’s property. If a parameter has the same name as a class property, **`this.property`** ensures we’re using the object’s value, not the parameter.

```dart
class TaskState {
  TaskState({
    this.tasks = const [],
    this.taskState = ApiState.initial,
    this.error,
  });

  final List<TaskModel> tasks;
  final ApiState taskState; // = ApiState.initial;
  final String? error;

  TaskSate copyWith ({List<TaskModel>? tasks, ApiState? apiState, String? error}) =>
    TaskState(
      tasks: tasks ?? this.tasks
      taskState: apiState ?? this.apiState,
      error: error ?? this.error,
    );
}

/// Usage
final  TaskState taskState  =  TaskState(…);
taskState  =  taskState.copyWith(tasks: …);
```
