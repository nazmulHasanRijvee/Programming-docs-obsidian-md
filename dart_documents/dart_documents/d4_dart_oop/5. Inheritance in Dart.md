Inheritance is a mechanism where a new class inherits properties and methods from an existing class.

Inheritance, Child (**Son**) class inherits properties/ variables and methods from the **Father** class. **`extends`** keyword is used to inherit from a class.

Here, **Son** class inherits properties and methods from **Father** class. We can also have our own properties and methods in the child class.

**`super`** keyword is used to assign/initialize the **name** property of the parent class which is **Father** class here (Which is also doing the work of **Father** classes constructor or calling it). For more info see below.

**`@override`** indicates that this method replaces the parent class version of method or property with our own custom implementation.

```dart
class Father {
  Father({required this.name}) {
    print('$name Father object created');
  }
  
  String name;
  String land = '100 bigha';
  String house = 'Tin basha';

  void inComeSource() {
    print('Father income source: farming');
  }
}

class Son extends Father {
  Son({required super.name, required this.sonName});
  
  String sonName;
  String land = '200 bigha';
  String house = 'Concrete building';
  
  @override
  void inComeSource() {
    print('Son income source: App developer');
  }
}

void main () {
  Son nazmul = Son(name: 'Johir', sonName: 'Nazmul');
  
  print(nazmul.name);
  print(nazmul.land);
  print(nazmul.house);
  
  nazmul.inComeSource();
  
  print(nazmul.sonName);
}
```
