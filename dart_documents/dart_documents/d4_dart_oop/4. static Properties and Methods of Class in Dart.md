**`static`** keyword, without creating an instance or object of the class, we can access the static members using the class name directly. Static members are shared among all instances/objects of the class.

```dart
class Animal {
  Animal({required this.name});
  
  String name;
  static String className = 'Animal';

  static void test() {
    print('test');
  }
}

void main () {
  Animal dog = Animal(name: 'Tom');
  print('Animal Name: ${dog.name}');
  print('Class Name: ${Animal.className}');
  Animal.test();
}
```

## Static_Performance_Comparison

**`static`** does not preload everything in memory. **`static`** methods are Loaded when the class is loaded.

- Not executed until called
- Not allocating per-object memory

**Dart** does NOT eagerly execute **`static`** methods. It only stores a function reference. So, this:

```dart
class Validation {
    static String? emailValidator(...)
}
```

Does NOT mean:

- Regex runs automatically
- Code executes automatically
- Memory is allocated for results

It just means the function is attached to the class.

Let’s compare. Current Approach (**`static`**)

```dart
Validation.emailValidator(value);
```

Memory:

- No object created
- Only method call
- Very lightweight

Instance Approach

```dart
final validation = Validation();
validation.emailValidator(value);
```

Memory:

- Allocates an object
- Stores object reference
- Calls method on instance

Overhead? Very tiny. Almost negligible. But unnecessary.

For pure stateless utility functions like validation:

- **Static** is correct.
- Cleaner.
- Less memory usage.
- No unnecessary instantiation.
