In **Dart**, instance variables are initialized before the object itself is fully created. Order of execution (simplified):

- Memory is allocated for the object
- Field initializers run
- Constructor body runs

At step 2, **Dart** does not allow accessing another instance member, because:

- **`foodRecipes`** which is a map belongs to the same object
- The object is not fully initialized yet

So, this is illegal:

```dart
final Food food = Food.fromJson(foodRecipes); // ❌ foodRecipes not ready
```

We can solve this by moving the logic into the **constructor** and using **`late`** keyword this way its safe cause **constructor’s** run after instance member exist.

```dart
FoodController() {
  food = Food.fromJson(foodRecipes);
}
```

We can also use **`static`** keyword (only if data is constant) if **`foodRecipes`** is shared and never changes. But **`static`** means shared across all instances which is NOT ideal for controllers in most apps.

```dart
class FoodController {
  static final Map<String, dynamic> foodRecipes = { ... };
  final Food food = Food.fromJson(foodRecipes);
}
```

The best way would be using a method/function (recommended) or a getter function using **`get`**.

```dart
class FoodController {
  Food? food;
  List<Recipes>? recipes;
  
  void getFood() {
    final food2 = Food.fromJson(foodRecipes);
    food = food2;
    recipes = food?.recipes;
  }
  
  Food get food => Food.fromJson(_foodRecipes);
}
```
