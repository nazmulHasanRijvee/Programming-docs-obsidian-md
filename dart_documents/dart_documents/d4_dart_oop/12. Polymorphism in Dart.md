Polymorphism means changing or redefining a property or method of a Parent class in a Child class, usually through overriding (**`@override`**). Overriding can be mandatory (abstract/interface methods) or optional when implementing inherited methods.

It works with inheritance (**`extends`**) and interfaces (**`implements`**).

Polymorphism allows our **`gateway`** variable to point to different objects (**Bkash**, **Nagad**), and the correct overridden method is executed at runtime depending on the object type. Polymorphism lets us declare an interface variable first then decide the actual object type later. polymorphism is like same method call **`.cashIn(amount)`** But different behaviors depending on the object (**Bkash** or **Nagad**).

```dart
class PaymentGateway {
  void cashIn(double amount);
  void cashOut(double amount);
}

class Bkash extends PaymentGateway {
  @override
  void cashIn(double amount) {
    print("Bkash: Cash in free");
  }
  
  @override
  void cashOut(double amount) {
    print("Bkash: Cash out charge 20 taka per 1000 taka");
  }
}

class Nagad extends PaymentGateway {
  @override
  void cashIn(double amount) {
    print("Nagad: Cash in free");
  }
  @override
  void cashOut(double amount) {
    print("Nagad: Cash out charge 10 taka per 1000 taka");
  }
}

void main() {
  String userChoice = "Nagad";
  double amount = 5000;
  
  late PaymentGateway gateway;
  
  if (userChoice == "Bkash") {
    gateway = Bkash();
  } else if (userChoice == "Nagad") {
    gateway = Nagad();
  } else {
    throw Exception("Invalid payment option");
  }
  
  gateway.cashIn(amount);
  gateway.cashOut(amount);
}
```
