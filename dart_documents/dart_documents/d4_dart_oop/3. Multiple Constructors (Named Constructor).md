Different constructors for different needs. Multiple constructors are just Named Constructors in **Dart**

We can define another constructor using **ClassName.constructorName** syntax and assign the values using colon **`:`** shorthand (of **`{}`** for single line code) with constructors

```dart
class Size {
  Size(this.height, this.width);

  double height;
  double width;

  Size.square(double side)
  : height = side, width = side;

  void printSize() => print('height: $height, width: $width');
}

void main () {
  final Size rectangle = Size(10, 15);
  rectangle.printSize(); // 10.0, 15.0

  final Size square = Size.square(10);
  square.printSize(); // 10.0, 10.0
}
```

> **NOTE:** Use Primary & Concise Constructors for modern **Dart 3.13+** see d5 part 2 of dart OOP doc for more info
