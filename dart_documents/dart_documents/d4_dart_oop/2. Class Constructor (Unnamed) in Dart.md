Constructor is A special method that:

- Runs automatically when creating a new object instance
- Initializes the object's properties and state
- Sets up any required dependencies or configurations

The default Constructor is also called the Unnamed Constructor. Key concepts:

- **`required`** → Makes parameters mandatory (compile-time enforcement)
- **`this.property`** → References the current instance's property (SEE [[8. this keyword & copyWith() method]])
- Named parameters → Improve readability and prevent argument order errors

Best practices:

- Use named parameters for better API clarity
- Mark essential parameters as **`required`**
- Set default argument/value make it nullable (`int?`) for optional parameters
- Keep initialization logic simple and focused

Basically, constructor is a method or function that runs automatically when an object is created and we can initialize variables when creating the object.

```dart
class Mobile {
  Mobile ({
    required this.year,
    required this.modelName,
    required this.brandName
  });
  
  int year;
  String modelName;
  String brandName;

  charging () {
    print('Mobile Charging...');
  }
  
  unlock () {
    print('Mobile Unlocked...');
  }
}

void main () {
  Mobile iphone = Mobile(year: 2016,modelName: 'iPhone x',brandName:  'Apple');
  
  print('Model Name: ${iphone.modelName}');  iphone.charging();
  
  iphone.unlock();
}
```

> **NOTE:** Use Primary Constructors for modern **Dart 3.13+** see d5 part 2 of dart OOP doc for more info.
