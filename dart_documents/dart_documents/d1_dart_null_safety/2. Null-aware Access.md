When we don’t know if an Object is **null** or not, use **`?.`** (null-aware access) to safely access its members. **`?.`** it says if the thing before me is not **null**, go ahead and do what’s after me, otherwise just show **null** instead of throwing an error cause **`.length`** does not take **null** and skip it.

```dart
void main() {
  String? name;
  print(name?.length);
}
```

Output: **null**
