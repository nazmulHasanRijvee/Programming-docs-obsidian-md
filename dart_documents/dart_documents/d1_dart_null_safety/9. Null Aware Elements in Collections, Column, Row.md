In **Dart 3.8+** & **Flutter 3.32+**. We can use null aware elements (**`?`**) instead of writing **`if-else`** block inside Lists, Sets and Maps

Like if a widget, builder or method can **return null**, so we have to check it before displaying it in the Widget Tree. If it’s not **null** then the widget is displayed.

Before or old way:

```dart
Column(
    children: [
       Text('Title'),

       If(subTitleWidget != null) subTitleWidget,

       If(iconWidget != null) iconWidget,

       If(footerWidget != null) footerWidget,
    ],
)
```

New way after null aware elements. Less boilerplate code:

```dart
Column(
    children: [
       Text('Title'),

       ?subTitleWidget,

       ?iconWidget,

       ?footerWidget,
    ],
)
```

> **NOTE:** But make sure that widget has to be nullable.

---
## Difference with Spread Operator:

**`?item`** means conditionally insert if non-null and **`...?list`** means spread list (paste list) if non-null.

**`?item`** adds one nullable item

```dart
Row(
  // …
  [
    ?widget
  ]
)
```

While **`…?list`** adds many nullable items (if not **null**)

```dart
Row(
  // …
  [
    …?widgets
  ]
)
```

---
## Importance:

**Dart** added this because **Flutter** developers write collection literals CONSTANTLY:

- **`children: []`**
- **`actions: []`**
- **`items: []`**
- **`slivers: []`**

And adding null-check boilerplate became annoying.
