We can use null aware operator **?.** in List and Map’s too.

Here **`?.`** checks if the List itself is **null**.

```dart
String? a;
String? b;
var list = [a, b];

print(list);  // [null, null]
```

With map key accessing. If **scores** is **null** → returns **null** safely but if key doesn’t exist → also returns **null**

```dart
Map<String, int>? scores;
print(scores?['math']); // null if scores is null
```
