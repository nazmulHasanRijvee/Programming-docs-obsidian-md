**`??=`** assigns a value only if the variable is **null**. Assigns **`Dhaka`** because **`city`** is **null**

```dart
void main() {
  String? city;
  city ??= "Dhaka";
  print(city);
}
```

Output: **Dhaka**

---
## Usage

Assigns a value on if the variable is **null**. It replaces this:

```dart
if (startingPosition == null) {
   startingPosition = position;
}
```

Using null-aware assignment operator:

```dart
startingPosition ??= position;
```

> **NOTE:** Useful when we want to assign a starting value or initial value and keep it stored there (won’t change). First GPS value → store as starting point and later updates → ignore. Or Pagination Page number
