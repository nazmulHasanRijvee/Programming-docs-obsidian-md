**`!`** null assertion tells **Dart** I know this value is not **null**, if we’re wrong, it will crash at runtime. Basically, converts nullable to non-nullable.

But its highly risky make sure we check the **null** variable before with **if** conditioning

```dart
void main() {
  int? age = 20;

  if (age == null) return; // make sure to check it

  int sureAge = age!;

  print(sureAge);
}
```

Output: **20**
