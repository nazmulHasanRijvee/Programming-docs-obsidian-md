The problem first, suppose we have a **List** of **`Student`** class instances and we want to sort them using **`.sort()`** method.

But **Dart** doesn’t know how to compare two students (instances of **`Student`**). It will throw this error “type '**`Student`**' is not a subtype of type '**`Comparable<dynamic>`**' in type cast.”

```dart
class Student {
  const Student(this.marks);
  final int marks;
  
  @override
  String toString() {
    return 'Marks: $marks';
  }
}

void main () {
  final List<Student> students = [
    Student(90),
    Student(76),
    Student(81)
  ];
  
  students.sort(); // will throw error
  print(students);
}
```

---
## The_Solution

Make **`Student`** class implement **`Comparable<T>`** interface class. Then **`@override`** the **`compareTo()`** method that will take an instance (**`other`**) of **`Student`** as a parameter and compares current classes **`marks`** with **`other`** instances marks.

So, now **`.sort()`** method works and sorts based on marks in ascending order.

```dart
class Student implements Comparable<Student> {
  const Student(this.marks);
  final int marks;

  @override
  int compareTo(Student other) {
    return marks.compareTo(other.marks);
  }
  
  @override
  String toString() {
    return 'Marks: $marks';
  }
}

void main () {
  final List<Student> students = [
    Student(90),
    Student(76),
    Student(81)
  ];
  
  students.sort(); // sorts based on marks
  print(students);
}
```

For reverse order simply compare with **`other`** instance's **`marks`**.

```dart
class Student implements Comparable<Student> {
  // …
  @override
  int compareTo(Student other) {
    return other.marks.compareTo(marks);
  }
  // …
}
```
