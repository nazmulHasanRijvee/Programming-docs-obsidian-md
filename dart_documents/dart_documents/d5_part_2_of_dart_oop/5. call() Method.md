If our class defines **`call()`** method then the Object behaves like a function. The Object itself becomes callable like instead of **`add.call(…)`** we can do **`add(…)`**

Useful for (used in light and dark theme data of **Flutter**):

- Validators
- Command objects
- Dependency injection
- Functional programming

```dart
class Adder {
  int call(int a, int b) {
    return a + b;
  }
}

void main () {
  final add = Adder();
  final result = add(2, 3);

  print(result); // 5
}
```
