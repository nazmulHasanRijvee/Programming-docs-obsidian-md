**MOST IMPORTANT**, **`extends`** → Inherit implementation, works immediately because **`Dog`** inherited the implementation including the properties.

```dart
class Animal {
  String type = “Animal”;
  void eat() {
    print("Eating");
  }
}

class Dog extends Animal {}

// Usage
Dog().eat();
Dog().type;
```

**`implements`** → Inherit only the contract (method need to be overridden). Here we must implement every method. Nothing is inherited.

```dart
class Dog implements Animal {
  @override
  void eat() {
    print("Dog eating");
  }
}
```

Think of it like:

- **`extends`** = “Use my code”
- **`implements`** = “Follow my API”

| **`extends`** | **`implements`** |
| --- | --- |
| Inherits code | Doesn't inherit code |
| Override if needed | Must override everything |
| "is-a" relationship | Contract/API relationship |
