This is unique in **Dart**. In **Java**, we explicitly write

```java
interface Animal {}
```

In **Dart**, every class automatically becomes an interface. When we implement it as an interface class using implements

Notice, **`Animal`** isn’t declared as interface. That’s why it’s called an Implicit Interface. Mental Model, every **Dart** class can be used as an interface.

```dart
class Animal {
  void eat() {
    print("Eating");
  }
}

// Implementing interface
class Dog implements Animal {
  @override
  void eat() {
    print("Dog is eating");
  }
}
```
