We can show a custom print of class instead of showing **Instance of Class_name** this. We just have to override the **`toString()`** method of the class. So, if we print an object of **Book** class instead of showing **Instance of Book** it will show our custom thing.

```dart
class Book {
  // …
  
  @override
  String toString() {
    return 'Book(title: $title, authorName: $authorName, …'
  }
}

print(book);
```
