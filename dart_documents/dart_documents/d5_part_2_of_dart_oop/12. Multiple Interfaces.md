**Dart** doesn't support multiple inheritance:

```dart
class C extends A, B {} // wrong
```

But it does support implementing multiple interfaces. Here, **Bird** promises to implement both APIs. This avoids the "diamond problem" that multiple inheritance can cause.

```dart
class Animal {
  void eat() {}
}
class Flyable {
  void fly() {}
}
class Bird implements Animal, Flyable {
  @override
  void eat() {}
  @override
  void fly() {}
}
```

---
## Use_Cases_in_Flutter

**`extends`** (Very common):

- **`State<MyWidget>`**
- **`StatelessWidget`**
- **`ChangeNotifier`**

**`implements`** useful when defining contracts (e.g., repositories, services, or custom APIs in clean architecture).

Multiple interfaces occasionally used in larger projects where a class needs to satisfy several contracts.

## Final_Mental_Model

```text
extends
   ↓
"I want your code."
----------------------------------------------------------
implements
   ↓
"I don't want your code.
I only promise to provide the same methods."
-----------------------------------------------------------
Implicit Interface
   ↓
"Every Dart class can be used as an interface."
------------------------------------------------------------
Multiple Interfaces
   ↓
"One class can promise multiple contracts."
```
