We use **iterables** every day. In **Dart**, collections like **List**, **Set** and anything else we can loop over (for loop) are iterables.

If we want our own custom class to have that same ability but without exposing data, use **`Iterable`** class. Without **`Iterable`** to loop over it we have to expose our list of letters using a getter method.

```dart
class Letter {
  final String letter;
  Letter({required this.letter});
}
class Words {
  final List<Letter> _letters = [];
  List<Letter> get letters => _letters;
}
```

But inheriting the **`Iterable`** class and overriding or implementing the **`iterator`** getter property to that lists `.iterator` (since we’re wrapping a **List**) we get iterable (loop over) functionality on the **Word** class now. And also, a bunch of other **List** properties like:

- **`words.first`**
- **`words.firstWhere()`**
- **`words.map()`** etc.

Are accessible in **Word** class now, all without exposing internal data.

```dart
class Words extends Iterable<Letter> {
  static final List<Letter> _letters = [];
  @override
  final iterator = _letters.iterator;
}
void main () async {
  final words = Words();
  for(final letters in words) {
    print(letters);
  }
  print(words.first);
}
```

> **NOTE:** We can ensure security or encapsulation using this trick.
