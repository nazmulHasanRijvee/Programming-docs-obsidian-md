We can use a custom named constructor (Multi-Constructor Concept) to automatically take a **Map** and return an object using **`.toClass_name(…):`**

> **NOTE:** There’s also **`.fromJson`** named constructor for doing the exact thing used in modeling

```dart
class Book {

  const Book({
    required this.title,
    required this.author,
    required this.category,
    required this.price,
  });

  final String title;
  final String author;
  final String category;
  final double price;

  void displayInfo() {
    print('Title: $title');
    print('Author: $author');
    print('Category: $category');
    print('Price: \$$price');
  }

  Book.toBook(Map<String, dynamic> map)
      : title = map['title'],
        author = map['author'],
        category = map['category'],
        price = map['price'];
}

void main () {
  final bookMap = {
    'title': 'Data Structures and Algorithms',
    'author': 'John Doe',
    'category': 'Computer Science',
    'price': 49.99,
  };

  final book = Book.toBook(bookMap);
  book.displayInfo();
}
```
