Use Cascade Operator (**`..`**) when we want to perform multiple operations on the same object or instance of a class. And the operations or methods doesn’t return anything (**`void`** or **`Future<void>`**), only used to set, modify or run things in the object.

Here we are setting the **name** property calling **`printName()`** and **`greet()`** methods of the object, when the object or instance is created. No need to write **person** for 3 times.

Semicolon (**`;`**) is added after the last operation.

```dart
class Person {
  String name = 'John';
  void printName() {
    print(name);
  }
  void greet() {
    print('Hello $name');
  }
}

void main () {
  final Person person = Person()
      ..name = "Nazmul"
      ..printName()
      ..greet();
  // Or
  person
      ..name = "Billy"
      ..printName()
      ..greet();
}
```

Output:

```text
Nazmul
Hello Nazmul
Billy
Hello Billy
```
