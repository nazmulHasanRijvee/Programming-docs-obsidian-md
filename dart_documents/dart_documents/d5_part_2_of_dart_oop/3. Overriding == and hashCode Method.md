The problem first, by default **Dart** compares Object identity (memory location), not the values inside the object.

So even if we create two objects (**`u1`**, **`u2`**) of the same Class (**User**) with the same name or value (**"Nazmul"**), they’re different objects in the memory. So, **`u1 == u2`** will return **false**.

```dart
class User {
  final String name;
  const User(this.name);
}
void main () {
  final u1 = User("Nazmul");
  final u2 = User("Nazmul");
  print(u1 == u2); // false
}
```

---
## The_Solution

**`@override`** the **`bool operator ==`** method that will take an **`Object`** data type. Then check if that **object** matches with current classes data type (**User**) and if **object**’s value (**name**) matches with the current classes value (**name**).

If both matches then **`u1 == u2`** returns **true**. Using this pattern, we can check if different objects of same Class type have same value or not.

Also override the **`hashCode`** getter method to the common value’s (**name**) **`.hashCode`**. So, **`hashCode`** remains same for multiple objects with the same value(**name**).

```dart
class User {
  final String name;
  const User(this.name);
  @override
  bool operator ==(Object other) {
    return other is User && other.name == name;
  }
  @override
  int get hashCode => name.hashCode;
}
void main () {
  final u1 = User("Nazmul");
  final u2 = User("Nazmul");
  print(u1 == u2); // true
}
```

Because collections like **`Set`**, **`Map<…>`** use **`hashCode`** for fast look up. If two objects are (**`==`**), they must have the same **`hashCode`** otherwise weird bugs happen. Like, without overriding **`hashCode`** returns **false**.

```dart
final users = {
  User("Nazmul"),
};
print(users.contains(User("Nazmul"))); // false
```

After overriding returns **true**.

```dart
print(users.contains(User("Nazmul"))); // true
```

## Usage

Very common in **Flutter**. Packages like **`equatable`** generate these automatically. Also used in:

- model classes
- caching
- **`Set`**’s
- **`Map`**’s
- state comparison
