In **Dart**, instead of the class name as magic identifier to mean “constructor” starting from **Dart 3.13+** there’s a universal keyword like **`new`** for this.

Before:

```dart
class User {
  User(String name);
}
```

Now it becomes:

```dart
class User {
  new(String name);
}
```

**`new`** means "I'm declaring a normal generative constructor here" and it gets more interesting with named constructors or multiple constructors. Before:

```dart
class User {
  User(String name);
  User.guest();
}
```

Now:

```dart
class User {
  new(String name);
  new guest();
}
```

Notice **`User.guest()`** becomes **`new guest()`**, **Dart** team explicitly designed this syntax to avoid repeating the class name (Specially if the class name is really long).

---
## Factory_Constructor_(Same_Idea)

Before:

```dart
class User {
  factory User.fromJson(Map<String, dynamic> json) {
    // ...
  }
}
```

Now:

```dart
class User {
  factory fromJson(Map<String, dynamic> json) {
    // ...
  }
}
```

This is mainly removing redundant class-name repetition. So, the mapping becomes:

| OLD                         | NEW                    |
| --------------------------- | ---------------------- |
| **`User()`**                | **`new()`**            |
| **`User.create()`**         | **`new create()`**     |
| **`factory User()`**        | **`factory()`**        |
| **`factory User.create()`** | **`factory create()`** |
