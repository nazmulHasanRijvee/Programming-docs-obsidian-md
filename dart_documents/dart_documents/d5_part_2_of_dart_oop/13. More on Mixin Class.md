In **Dart**, a class can use multiple **mixins**. Here the **Duck** class gets behavior from both **mixins**.

```dart
mixin Fly {
  void fly() => print("Flying");
}

mixin Swim {
  void swim() => print("Swimming");
}

class Duck with Fly, Swim {}

// usage

void main() {
  final duck = Duck();
  duck.fly();
  duck.swim();
}
```

Output:

```text
Flying
Swimming
```

> **NOTE:** If two **mixins** have the same method, the rightmost **mixin** wins. If all define **`hello()`**, **B**’s version is used.

```dart
mixin A {
  void hello() => print("A");
}

mixin B {
  void hello() => print("B");
}

class Test with A, B {}
```

## On_Keyword_with_mixin_Class

Sometimes a **mixin** only makes sense for certain classes. Use **`on`** keyword so that child class inheriting that parent class will get the **mixin**.

```dart
class Animal {
  void eat() => print("Eating");
}

mixin CanRun on Animal {
  void run() {
    eat(); // Allowed because Animal has eat()
    print("Running");
  }
}
```

Now this works:

```dart
class Dog extends Animal with CanRun {}
```

But this does not, because Car isn’t an Animal:

```dart
class Car with CanRun {} // Error
```

Mental model, the **`on`** keyword says “You can only apply this **mixin** to classes that extend or implement this type." It's mainly used when the **mixin** depends on methods or fields from another class.

## Mixin_vs_Inheritance

Inheritance (**`extends`**) used when there is an "is-a" relationship. Like a dog is an animal.

```dart
class Animal {}

class Dog extends Animal {}
```

**Mixin** (**`with`**) used to add extra abilities. The bird isn't a **CanFly**. It simply has the flying behavior. Think of it as adding a skill.

```dart
mixin CanFly {}

class Bird with CanFly {}
```

Mental model:

```text
extends
↓
Identity
(A Dog is an Animal)
--------------------------
with
↓
Ability
(A Bird can Fly)
```

## Mixin_vs_Interface

Interface (**`implements`**) says "You must write these methods". The interface gives no implementation.

```dart
abstract class Printer {
  void printDoc();
}

class HP implements Printer {
  @override
  void printDoc() {
    print("Printing...");
  }
}
```

**Mixin** says "Here's some ready-made code". Now **Service** gets **`log()`** automatically.

```dart
mixin Logger {
  void log(String msg) {
    print(msg);
  }
}

class Service with Logger {}
```

## Quick_Comparison

| Feature               | Inheritance (**`extends`**) | Mixin (**`with`**) | Interface (**`implements`**) |
| --------------------- | --------------------------- | ------------------ | ---------------------------- |
| Reuse code            | ✅                           | ✅                  | ❌                            |
| Add behavior          | ❌                           | ✅                  | ❌                            |
| Must override methods | Sometimes                   | No                 | Yes                          |
| Represents "is-a"     | ✅                           | ❌                  | ❌                            |
