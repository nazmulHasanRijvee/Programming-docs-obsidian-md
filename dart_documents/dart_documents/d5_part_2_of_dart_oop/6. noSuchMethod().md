Whenever we call something that doesn't exist like **`obj.hello()`**, normally **Dart** throws **NoSuchMethodError**. We can intercept it and specify it to show something instead of crashing immediately.

Exists mostly for:

- Mocking libraries
- Proxies
- Dynamic APIs

Modern **Dart** strongly prefers compile-time checking, so we almost never write this ourself.

```dart
class Test {
  @override
  dynamic noSuchMethod(Invocation invocation) {
    print("Method doesn't exist");
  }
}

void main () {
  final test = Test();

  test.anything(); // Method doesn't exist
}
```
