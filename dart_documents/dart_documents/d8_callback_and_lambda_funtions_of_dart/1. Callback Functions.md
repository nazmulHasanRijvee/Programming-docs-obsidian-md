

Callback functions call a function from another file like **`home_page`** it does not return a value, but it may take a parameter. 3 common functions are:

---
## VoidCallback

**`VoidCallback`** calls a function, does not accept parameter and return type is void means nothing is returned. Used for buttons, simple taps where not data is passed.

```dart
VoidCallback   function_name;
```

---
## ValueChanged

**`ValueChanged<T>`** callback function accepts a parameter and does not return any value. Ensures type safety. Used for checkboxes, sliders that pass a value. It has to be wrapped by an anonymous or lambda function like **`(value) => function_name`** in the assigned page. (value) comes internally from flutters checkbox.

```dart
ValueChanged<bool?>? function_name;
```

> **NOTE:** Use this when we need a value from another class (notifier class of Provider) or file to be passed internally **`(value) {}`** from Flutter and access it in another file (Usually UI). Like this, in Provider or another class.

```dart
void getValue({required ValueChanged<int> onTap}){
  final int num = 0;
  onTap(num);
}
```

In UI or other,

```dart
final provider = context.read<MainNavProvider>();
provider.getValue(onTap: (value){
  debugPrint('$value');
});
```

---
## Function_(ValueChanged_Alternative)

**`Function()`** callback accepts one or more parameter and does not return any value. But it’s not type safe. It’s needed for flexibility. Used for sliders, checkboxes. Works like **`ValueChanged`** for **`(value) =>`**.

```dart
final Function(bool?)?     function_name:
final void Function(String, bool) onTap;
```

Type can be **`void`** if it returns nothing simply passes the values internally to another class

```dart
final void Function(String, int) onChanged;
final bool Function(int) onTapped; // returns a bool
```

> **NOTE:** **`final`** can be used for **`VoidCallback`** and **`VoidChanged`** so **`const`** be used for optimization.
>
> **NOTE-2:** But if we need more than one parameter in the function than **`Function()`** callback is better approach
