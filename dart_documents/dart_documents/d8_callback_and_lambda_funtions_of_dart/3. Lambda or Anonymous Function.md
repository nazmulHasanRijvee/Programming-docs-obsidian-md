Lambda function is an anonymous (does not have any name) function that can be defined on the spot. It can take a parameter too.

```dart
() =>  or ( ) {  }
(int value) =>
```

It is mostly used for button callbacks

This lambda returns the cancelNewTask function itself.

```dart
onCancel: () => cancelNewTask,
```

This calls the **`cancelNewTask()`** function in the lambda function. In this way for logic can be applied for future use.

```dart
onCanel: () => cancelNewTask(),
```
