We can also pass a function as parameter or argument of a class or function specifying the data type **`Future<void> Function()`** and then just call it.

```dart
class ProductDialog extends StatefulWidget {
  final Future<void> Function() fetchProductsData;
  const ProductDialog({
    super.key,
    required this.fetchProductsData,
  });
…
await fetchProductsData;
```

Or

```dart
class AuthProvider {
  static String? get token => _token;
  …
}
class APICaller {
  final String? Function() getToken;
  APICaller({required this.token);
  …
  {
     “token” : getToken,
  …
}
final apiCaller = APICaller(getToken: () => AuthProvider.token);
```

> **NOTE:** Use this when we want to get the latest data from a class instead of using the old one (snapshot). It’s like **`getToken()`** when called every time it gets the lates token. Here instead of a callback think of it like a passable parameter in classes or methods.
