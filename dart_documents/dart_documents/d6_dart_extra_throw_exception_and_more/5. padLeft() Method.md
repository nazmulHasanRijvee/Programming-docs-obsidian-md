**`.padLeft(..., …)`** is used to ensure a number is a specific **2** digit even if it is missing a digit like it’s a single digit number **5** then specified character or **`String`** like **'0'** will be added automatically to the left to make it **2** digit. This is standard media formatting (music players, video players). Example:

```text
without it 5
with it 05
```

It works with **`String`** data type.

```dart
Duration(seconds: 5).inSeconds.toString().padLeft(2, '0') // 05

Duration(seconds: 50).inSeconds.toString().padRight(2, '0'); // 50
```

> **NOTE:** There’s also **`.remainder()`** (for numbers) and **`.padRight()`** (works with strings) method too
