**`.map(...)`** method iterates over the List and applies the provided logic to each item, producing an **`Iterable<T>`** of mapped values. Basically, it’s a loop where **`item`** holds each map in iteration.

**`return [formattedTime, condition, temp]`** for each item, map returns a list with three elements. So, the mapped iterable contains elements like **`<Iterable**>['1 PM', 'Clouds', '27.5']`**.

**`.toList()`** converts the iterable produced by **`.map(...)`** into a concrete **List**. If the original **`json['hourly']`** was non-null, we now have a **List** **`List<dynamic>>`**.

```dart
final hourlyList = mapList .map((item) {
   // …
   return [formattedTime, condition, temp];
 }).toList();
```

> **NOTE:** If we use map unpacking in API response (**`json[hourly]`**), we have to make sure to use null safety(**`?.`** , **`?? []`**;) and type safety (**`as List<dynamic>?`**)
