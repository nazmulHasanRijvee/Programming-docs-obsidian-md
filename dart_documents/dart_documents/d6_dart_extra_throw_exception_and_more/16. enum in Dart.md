**`enum`** stands for enumeration. It lets us define a fixed set of named values. Think of it as “A variable that can only take one value from a small predefined list.” Examples of when **enums** are perfect:

- Choosing between light and dark mode
- Gender selection
- App states (loading, success, error)
- Our case: height input type (cm vs feet + inch) for **`SegmentedButton()`**

So, basically by using **`enum`** we can create our custom type or OPTIONS for choosing (like **`bool`** has **`true`** or **`false`**) and define its fixed set of values. **`enum HeightType {cm, feetInch}`** This creates a new custom type called **`HeightType`**. It has exactly two possible values. Nothing else is allowed.

- **`HeightType.cm`**
- **`HeightType.feetInch`**

Using **`enum`** in **Flutter**:

First declare the num like this outside of any class

```dart
enum HeightType { cm, feetInch }
```

Create a variable of our custom type like this and initially select a value.

```dart
HeightType heightType = HeightType.cm;
```

Check its value using **`if`**

```dart
if (heightType == HeightType.cm) {
  print("User wants to enter cm");
}
```

Use in a **`switch`**

```dart
switch (heightType) {
  case HeightType.cm:
    print("Centimeters");
    break;
  case HeightType.feetInch:
    print("Feet & Inch");
    break;
}
```

Changing **`enum`** values using **`ElevatedButton()`** we can also use **`SegmentedButton()`**.

```dart
ElevatedButton(
  onPressed: () {
    setState(() {
      heightType = HeightType.cm;
    });
  },
  
  child: Text("Use CM"),
),

ElevatedButton(
  onPressed: () {
    setState(() {
      heightType = HeightType.feetInch;
    });
  },
  
  child: Text("Use Feet & Inch"),
),
```

Get all **`enum`** values using **`.values`** which returns a **`List`** of **`enum`** values

```dart
HeightType.values;
// -> [HeightType.cm, HeightType.feetInch]
```

Get **`enum`** as a **`String`** using **`.name`**

```dart
print(HeightType.cm.name);
```

> **NOTE:** **`enum`** can be used with code generation package **`json_serializable`** and enhanced **`enum`**’s can be created using **`@JsonValue()`**, **`@JsonEnum()`** annotations. For more info see flutter dart build_runner and code generation doc

## Another_Usage_of_enum

**`enum`** can be used as a replacement of **`static const _acccessTokenKey`** constant variables for KEY-VALUE pair databases. By saving the **`enum.value`** as a **`String`** using **`CacheKey.accessToken.name`** which returns **`"accessToken"`** **`String`**

```dart
enum CacheKey {
  accessToken,
  refreshToken,
  language,
  themeMode,
  user,
}

class SharedPreferencesService {
  // ...

  @override
  Future<void> save<T>(CacheKey key, T value) async {
    switch (T) {
      case const (String):
        await prefs.setString(key.name, value as String);
        break;

      case const (int):
        // ...
  }

  @override
  T? get<T>(CacheKey key) {
    return switch (T) {
      const (String) => prefs.getString(key.name) as T?,
      // ...
    };
  }
  // ...
}

sharedPreferencesService.save<String>(CacheKey.accessToken, "abc123");
sharedPreferencesService.get<String>(CacheKey.refreshToken, "abc123");
```

It can be used as an alternative of Routes static const variables too with an additional property (**`path`**) for each **`enum`** options (**`home("/home")`**) using the enum constructor like this:

```dart
enum Routes {
  splash('/splash'),
  onboarding('/onboarding'),
  
  login('/login'),
  register('/register_screen'),

  homeScreen('/home_screen'),
  chatScreen('/chat_screen'),
  
  const Routes(this.path);
  final String path;
}

/// Usage
GoRoute(
  name: Routes.login.name,
  path: Routes.login.path,
  builder: // ...
);
```

## Dot_Short-Hands_for_enum

**Dart 3.10+** introduced “contextual shorthand” for **`enum`** values inside **Flutter** widget properties. When a parameter expects an **`enum`** type like this **`crossAxisAlignment: CrossAxisAlignment`** **Dart** already knows the type. So instead of repeating **`CrossAxisAlignment.start`** we can simply write **`.start`**

Old way:

```dart
HeightType heightType = HeightType.cm;
```

New dot shorthand:

```dart
HeightType heightType = .cm;
```

> **NOTE:** Works with other **`enum`**’s ( **`alignment:`** , **`axis:`** , **`fit:`** etc.) too. **Dart** chooses shorthand automatically based on context.

Dot shorthand for **`this`**:

```dart
.title  ≡  this.title
```

Dot shorthand for `enum`s:

```dart
.start  ≡  CrossAxisAlignment.start
```
