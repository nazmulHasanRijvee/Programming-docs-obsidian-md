Unlike regular **`Map`** in **Dart**, **`LinkedHashMap`** preserves the insertion order like who was added last. Useful for creating and limiting LRU (Least Recently Used) cache.

It solves problems like last visited screen or movie. Suppose:

```text
Visit 1
Visit 2
Visit 3
Cache = [1,2,3]
```

Then user revisits:

```text
Movie 1
Movie 1 should become "recently used".
```

Cache becomes:

```text
[2,3,1]
```

Now user opens Movie 4, Notice how Movie 1 survived because it was recently used:

```text
Remove 2
Cache = [3,1,4]
```

This keeps the most recently accessed screens or movies (ordered by recent). Create it using OOP:

```dart
import 'dart:collection';
final LinkedHashMap<int, MovieDetailsModel> _cache =    LinkedHashMap();
```

Then get values from it if available (matches key which is unique ID):

```dart
MovieDetailsModel? getMovieFromCache(int movieId) {
  if (!_cache.containsKey(movieId)) {
    return null;
  }
  final movie = _cache.remove(movieId)!;
  _cache[movieId] = movie;
  return movie;
}
```

Add or save values with unique ID (for retrieving later):

```dart
void saveMovie(
  int movieId,
  MovieDetailsModel movie,
) {
  _cache.remove(movieId);  // not important, just checking
  if (_cache.length >= 3) {
    _cache.remove(_cache.keys.first);
  }
  _cache[movieId] = movie;
}
```
