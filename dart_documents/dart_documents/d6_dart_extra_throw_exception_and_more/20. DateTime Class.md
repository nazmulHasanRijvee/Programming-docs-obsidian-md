If we have a time stamp ("dt": 1731079200), we can convert it in a readable time using **`DateTime.fromMilisecondsSinceEpoch(...)`**. This method prints full UTC/local date.

**`timestamp*1000`** means converting it to milliseconds.

```dart
int timestamp = 1731079200;
DateTime date = DateTime.fromMillisecondsSinceEpoch(timestamp * 1000);
print(date);
```

By default, **`DateTime.fromMillisecondsSinceEpoch()`** gives local time. If we want UTC, pass the optional flag meaning set the **`isUtc : true`**.

```dart
DateTime utcDate = DateTime.fromMillisecondsSinceEpoch(timestamp * 1000, isUtc: true);
```

Or if we want to force local conversion using **`utcDate.toLocal()`** method.

```dart
DateTime localDate = utcDate.toLocal();
```

Converting String to DateTime:

If our API returns things like "2025-11-16T15:30:00Z" we can parse it using **`DateTime.parse()`**

```dart
String isoString = "2025-11-16T15:30:00Z";
DateTime dt = DateTime.parse(isoString);
```

More on DateTime:

Adding or Subtracting time

```dart
DateTime next = now.add(Duration(days: 5));
DateTime last = now.subtract(Duration(hours: 2));
print('Now: $now');
print('Next Week: $next');
print('Last Week: $last');
```

Comparing dates

```dart
DateTime a = DateTime(2023, 1, 1);
DateTime b = DateTime(2025, 11, 8);
print(a.isBefore(b)); // true
print(a.isAfter(b)); // false
print(a.isAtSameMomentAs(b)); // false
```

Difference between dates

```dart
DateTime start = DateTime(2025, 11, 1);
DateTime end = DateTime(2025, 11, 8);
Duration diff = end.difference(start);
print(diff.inDays);
print(diff.inHours);
print(diff.inMinutes);
```

Converting DateTime to String and then converting back

```dart
String str = '2025-11-08 20:45:00';
DateTime parsed = DateTime.parse(str);
print(parsed);
print(parsed.toIso8601String());
```
