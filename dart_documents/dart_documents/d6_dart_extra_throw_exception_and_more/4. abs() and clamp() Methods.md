**`.abs()`** is a method on numeric types (**`num`, **`int`, **`double`**) that returns the absolute value (non-negative). Example:

```text
(-5).abs() → 5
```

```dart
print(25.abs()); // 25

print(-25.abs()); // 25
```

---
## Clamp()

**`.clamp(min, max)`** is a method on num that limits a value to lie between two bounds. (prevents overflow and over-shrinking problems in **Flutter**)

- If **`progress`** < **`0.0`**, **`clamp()`** returns **`0.0`**.
- If **`progress`** > **`1.0`**, **`clamp()`** returns **`1.0`**.
- Otherwise, it returns **`progress`** unchanged.

```dart
progress = progress.clamp(0.0, 1.0); // Ensures safety
```

>**NOTE:** **`.clamp()`** returns a **`num`** object. In many cases **Dart** will accept it for a double variable, but if we need a strict double we can **`as double`** the result.
