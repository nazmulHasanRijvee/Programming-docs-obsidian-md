**`List.filled(n, value)`** creates **n** items all set to the same value. Use this, when we uniform default values. It creates a fixed-list (non-growable, **`.add()`** and **`.remove()`** will cause error) and sets limit of the List.

Properties:

- **`length`** → how many elements (limit of the list)
- **`fill`** → the value copied into every slot
- **`growable`** → by default false (fixed-size list)

```dart
List.filled(int length, T fill, {bool growable = false});
```

Example, every slot gets 0. Simple and fixed size by default.

```dart
var row = List.filled(5, 0);
print(row); // [0, 0, 0, 0, 0];
```

---
## Shared_Reference_Problem_(The_Trap)

This where most beginners get burned. Because **`List.filled()`** copies the same reference of the inner list into every row. All 3 rows point to the same list object in memory.

WRONG way to make a 2D matrix. If we modify the second index or element of the first list then all lists second element changes too! (Bug)

```dart
var matrix = List.filled(3, List.filled(3, 0));
matrix[0][1] = 99;
print(matrix);
// [[0, 99, 0], [0, 99, 0], [0, 99, 0]]  ← ALL rows changed!
```

## With_List.generate

**`List.generate()`** calls the lambda fresh each time, where each row is a brand-new **`List.filled()`** object in memory.

This means "I don't care about the index, just give me a fresh row."

Quick Mental Model:

```text
List.filled(4, 0)     → [0, 0, 0, 0] (same value, same reference if object)
List.generate(4, (i)  → [f(0), f(1), f(2), f(3)] (computed, always new)
```

```dart
var matrix = List.generate(
  3,
  (_) => List.filled(3, 0), // NEW list created for each row
);
matrix[0][1] = 99;
print(matrix);
// [[0, 99, 0], [0, 0, 0], [0, 0, 0]]  ← Only row 0 changed
```

> **NOTE:** There’s also **`.fillRange()`** method for replacing an index-range of the filled elements generated by **`List.filled()`**.
