**`max()`** comes from **Dart**’s math library so import this first.

```dart
import 'dart:math';
```

**`max(a, b)`** returns the larger of the two values and works with **`int`** and **`double`**. Examples:

```text
max(5, 10)    // → 10
max(3.5, 2)  // → 3.5
max(-1, 0)   // → 0
```

But here think of **`max()`** is like: “Give me the real value, but never less than X” **`max(value, safeMinimum)`** is a defensive programming pattern used to prevent crashes and edge cases.

**`max(_duration.inSeconds.toDouble(), 1.0)`** guarantees a minimum value of **`1.0`**. This is usually done to:

- Prevent division by zero
- Avoid broken animations
- Avoid progress bars with 0 max value

If we have a progress bar, and if **`_duration`** = 0:

```text
current / 0 ❌ CRASH
```

But with **`max()`**:

```text
current / 1.0 ✅ SAFE
```

```dart
final double maxSecond = max(_duration.inSeconds.toDouble(), 1.0);
```

## Common_Flutter_places_we’ll_use_this

In **`Slider()`** widgets **`max:`** property:

```dart
Slider(
  min: 0,
  max: max(duration.inSeconds.toDouble(), 1.0),
)
```

In **`LinearProgressIndicator()`** widgets **`value:`** property:

```dart
value: current / max(total, 1.0)
```

In Animation normalization:

```dart
t = elapsed / max(duration, 1.0);
```

> **NOTE:** There’s also **`min()`** method to enforce minimum **`min(volume, 1.0)`** capped at 100%.
