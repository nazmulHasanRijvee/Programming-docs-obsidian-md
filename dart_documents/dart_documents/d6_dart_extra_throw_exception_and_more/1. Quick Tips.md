For conversion we can use .**`toString()`**, **`toInt()`**, **`.toDouble()`** and **`.toList()`** etc. also **`.parse()`** and **`.tryParse()`**. There’s **`as double`**, **`as int`** etc. too

For loops beside **`for(var item in…)`** and **`.foreach()`** useful for API models:

- **`.map((e) => …)`** use it when we have a list of Maps or basically list of anything as **`for`** loop alternative  (**`.toList()`** might be need)
- And **`List.Generate(length, (index) {…}).toList()`** use it for when want to generate a list of objects/**Map**’s using elements from multiple list or for any list as **`for`** loop alternative

If using **`List.generate()`** in **`Row()`**/**`Column()`**, directly assign to **`children:`** (without **`[]`**) or use Spread Operator (**`…List.generate()`**) to unpack or insert in the List literal **`[]`**
