**`throw`** in **Dart** is used to raise an Exception/Error, which stops normal program execution and transfers control to the nearest error handler (usually a **`try-catch`** block). It’s how we tell **Dart** Something went wrong here stop and go handle this as an error.

**`Exception('Failed to load weather data')`** that’s creating a new **`Exception()`** object with a message string inside. So, this creates an error object carrying the message **"Failed to load weather data"**. Adding **`throw`** in front actually throws it (activates the error). It means immediately stop execution of this function and report an error with the message

```dart
Future<void> fetchWeather() async {
  // …

  if (response.statusCode == 200) {
    print('Weather data loaded successfully');
  } else {
    throw Exception('Failed to load weather data');
  }
}
```
