**`.firstWhere(() => …)`** method searches a List and returns the first element that matches a condition. Syntax is like this:

```dart
[…].firstWhere((element) => condition); // If condition is true element will be returned
```

Example:

```dart
[1,2,3].firstWhere((n) => n == 2);
```

Returns → 2

Example with an **`enum`**. Each **`enum`** has a **`.name`** property (**`ThemeMode.dark.name`** = **"dark"** or **`ThemeMode.light.name`** = **"light"**). So, **`(element) => element.name == theme`** means find the **enum** whose name matches the stored string.

Suppose, **theme = dark** then **firstWhere** checks:

- `system.name == "dark"` ❌
- `light.name == "dark"` ❌
- `dark.name == "dark"` ✅

So, it returns **`ThemeMode.dark`** and assigns it to **`_themeMode`**. Useful for getting theme mode from **shared_preferences** package

```dart
_themeMode = ThemeMode.values.firstWhere((element) => element.name == theme);
```

> **NOTE:** There’s also **`.removeWhere()`** method just like it for Lists. Check dart IDE files.
