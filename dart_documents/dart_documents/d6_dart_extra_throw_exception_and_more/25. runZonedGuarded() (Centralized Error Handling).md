Not every exception (error) can be caught with “**`try-catch`** block” in everywhere, **Dart** zones help us catch all uncaught asynchronous errors (not handled by **`try-catch`**) in one centralized place. Using **`runZonedGuarded()`**. It:

- Spawns a second zone
- Captures any uncaught error inside that zone
- Future errors, Timer errors & Microtask errors
- Stream errors (if unhandled)
- Errors from anywhere inside that zone

**`runZonedGuarded(…)`** function takes two parameters:

- A Void Callback method to run in its own guarded error zone
- A Callback method (**`onError`**) that gives us error and **`stackTrace`** internally which can be printed or logged

```dart
import 'dart:async';
void main () {
  runZonedGuarded(() {
    final int num = int.parse('a');
    print(num);
    }, (error, stackTrace) {
    print('error $error, stack Trace: $stackTrace');
  });
}
```

## In_Flutter

It wraps our entire app in a protected execution context. Like a safety net around our entire app execution.

**`runZonedGuarded()`** intercepts any uncaught errors and prevents the app from crashing silently. It provides:

- **Global error handling:** Catch errors from anywhere in the app
- **Better crash reporting:** Log and monitor errors in production using **Firebase Crashlytics**
- **Cleaner Code and Reliability:** Not mandatory to wrap every async call using try-catch and prevents silent crashes, unknown failures

> **NOTE:** It has been replaced by **`PlatformDispatcher`** (from **Flutter 3.3+**). Best practice is use **`FlutterError`** and **`PlatformDispathcer`** for global error/crash reporting. SEE f1 widgets and UI folders f13 flutter extras of basic doc

```dart
void main () {
  runZonedGuarded(() {
    runApp(const MyApp());
    },(error, stackTrace) {
    // handle uncaught errors here
    log(error);
    log(stackTrace.toString());
    // Send crash reporting service
    // like Firebase Crashlytics
  });
}
```
