This is a **Map** method. It adds a key if it doesn’t exist.

The anatomy:

- Key → the key to check in the **Map**
- **`() => value`** → a callback function that runs only if the key is missing, providing the value for the missing key
- Returns → the existing value if key exists or the newly inserted value

```dart
map.putIfAbsent(key, () => value);
```

Basic example, here the second call does nothing because **`'Alice'`** already exists.

```dart
Map<String, int> scores = {};

scores.putIfAbsent('Alice', () => 0);
scores.putIfAbsent('Alice', () => 99); // Alice already exists!

print(scores); // {Alice: 0}  ← 99 was never inserted
```

---
## Returning_Value

People often miss this, **`.putIfAbsent()`** returns the value (existing or new).

```dart
Map<String, int> counter = {};

int val = counter.putIfAbsent('x', () => 42);

print(val);     // 42
print(counter); // {x: 42}

int val2 = counter.putIfAbsent('x', () => 99);

print(val2); // 42
```

## Most_Common_Use_Case(Grouping)

If key **`'a'`** doesn't exist then callback runs **`() => []`** and inserts **`[]`** empty list.

Returns that **`[]`** reference.

**`.add('apple')`** appends to that empty list. Map now has **`{a: [apple]}`**.

On 'ant', if key 'a' already exists → returns existing list (**`[apple]`**) and **`.add('ant')`** appends it to list (**`{a: [apple, ant]}`**).

Basically, creates empty list if key missing then adds word to that list.

```dart
List<String> words = ['apple', 'ant', 'bat', 'banana', 'avocado'];

Map<String, List<String>> grouped = {};

for (var word in words) {
  grouped.putIfAbsent(word[0], () => []).add(word);
}

print(grouped); // {a: [apple, ant, avocado], b: [bat, banana]}
```
