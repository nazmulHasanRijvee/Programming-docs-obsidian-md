The **`.fold<T>()`** method in **Dart** reduces a collection (like a **List**) to a single accumulated value by iteratively combining each element with an existing value using a provided function  (Useful for calculating total or sum of prices or values)

It accepts two arguments:

- **initialValue** -> the starting value for the accumulator
- **combine** -> a **`ValueChanged<T>`** callback method that internally gives **`previousValue`** (accumulated result so far) and the current **`element`**, ultimately returning the new accumulated value.

Key Characteristics:

- Handles Empty Collections Unlike **`.reduce()`**, **`.fold()`** returns the **initialValue** if the collection is empty, preventing errors.
- Type Flexibility: The return type can differ from the element type of the collection (e.g., calculating the sum of **String** lengths returns an **int**).
- Immutability: It does not modify the original collection.

```dart
  List<int> list1 = [1 , 2, 3, 4];

  final total = list1.fold<double>(
    0,
    (previousValue, element) => previousValue + element
  );

  print(total);
```
