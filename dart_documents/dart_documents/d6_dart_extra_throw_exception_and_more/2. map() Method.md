**`.map()`** method doesn’t return a **List** instead it returns an **`Iterable<T>`**. **Iterable** is a lazy sequence, it’s a promise to produce values one by one, but it hasn’t actually done the work yet.

**List** is data sitting fully in memory, indexed, ready while **Iterable** is a recipe/blueprint, computes each item ON DEMAND.

**`.toList()`** forces evaluation, it walks through the iterable, computes every item, and dumps them into a real List in memory.

```dart
// returns Iterable<HomeSliderModel> —> lazy, no data yet
data.map((e) => HomeSliderModel.fromJson(e))
// returns List<HomeSliderModel> —> fully computed, in memory
data.map((e) => HomeSliderModel.fromJson(e)).toList()
```

> **NOTE:** Sometimes type error still remains in runtime because **`.toList()`** method converts **`Iterable<dynamic>`** to **`List<dynamic>`** which can’t be assigned to **`List<Model>`** type variable. In that case specify the type directly like this **`.map<Model>(…).toList()`**. Now **`Iterable<Model>`** to **`List<Model>`**.

## The_danger_of_Raw_Iterables

Every time we use it, it RE-Runs the transformation but with **`.toList()`** computed once and reused.

```dart
var numbers = [1, 2, 3];
var doubled = numbers.map((e) => e * 2); // Iterable
print(doubled.first); // computes again
print(doubled.last);  // computes again
for (var n in doubled) {} // computes AGAIN
var doubledList = doubled.toList();
print(doubledList.first); // just reads from memory
print(doubledList.last);  // just reads from memory
```

> **NOTE:** Don’t use **`.map()`** method for calculating **total** number of price from a **List** of objects. The total price won’t show up because **`.map()`** method doesn't actually execute the code inside its closure immediately. Instead, it returns a "lazy" **`Iterable<T>`**. The transformation (and in our case, the side effect of adding to **`total`**) only happens when we actually iterate over that result. For example, by calling **`.toList()`**, **`.length`**, or using it in a **`for`** loop. Since the result of our **`.map()`** call is never consumed, the code inside is never run, and **`total`** remains **0**.

Instead use [[9. firstWhere() Method]] , **`List.generate()`** and [[3. fold() method]] (recommended in this case) methods.
