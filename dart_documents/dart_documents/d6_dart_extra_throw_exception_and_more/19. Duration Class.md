**`Duration`** represents a span of time, not a date.

- 5 seconds
- 2 minutes
- 1 hour 30 minutes

It’s NOT a calendar date (that’s **`DateTime`**). **Flutter** converts everything internally into microseconds.

**`Duration`** (**`_duration`**) properties. Remember these are total values, not remainder values.

| Property | Value | Meaning |
| --- | --- | --- |
| **`_duration.inSeconds`** | 225 | total seconds |
| **`_duration.inMinutes`** | 3 | total whole minutes |
| **`_duration.inHours`** | 0 | total whole hours |
| **`_duration.inMilliseconds`** | 225000 | total ms |
| **`_duration.inMicroseconds`** | very big | internal unit |

Usage:

We can use Duration in many ways like delays using **`Future.delayed`**:

```dart
Future.delayed(Duration(seconds: 2));
```

In **`AnimationController`**

```dart
AnimationController(
  duration: Duration(milliseconds: 300),
)
```

Timers using **`Timer()`**

```dart
Timer(Duration(seconds: 1), () {});
```

Media, audio and video positions in seconds using **`position:`**

```dart
position: Duration(seconds: 42);
```

Formatting time (mm:ss, hh:mm:ss) using Duration:

If time is 3:45 then **`inMinutes`** → 3 and **`inSeconds`** → 45, we want 3:45 not 3:225. So we use **`.remainder()`** it means give me seconds LEFT after removing full minutes. **`.remainder(60)`** gives leftover seconds after minutes. Example:

```dart
Duration(seconds: 125)
inSeconds → 125
125 % 60 → 5
Result = 2:05
```

**`formatedDuration(…)`** this function accepts a **`Duration`** and returns a formatted String like mm:ss

**`inMinutes`** gives total full minutes. Example: **`Duration(seconds: 125)`** → 2

**`duration.inSeconds`** is total seconds

**`.padLeft(.., …)`** is used to ensure a specific digit like 2 of numbers even if it is missing a digit like it’s a single digit 5 then specified character/String like **`'0'`** will be added automatically to the left to make it two digit. This is standard media formatting (music players, video players). Example:

**without it 5**

**with it 05**

**`return '$minutes:${seconds.toString().padLeft(2, '0')}'`** This does 3 things convert seconds to **`String`**, ensure 2 digits using **`.padLeft()`** and interpolate final string (**`'2:05'`**)

```dart
String formatedDuration(Duration duration) {
  final int minutes = duration.inMinutes;
  final int seconds = duration.inSeconds.remainder(60);
  return '$minutes:${seconds.toString().padLeft(2, '0')}';
}
```

Formatting Hours:

Example: 01:05:09

```dart
String formatHMS(Duration d) {
  final hours = d.inHours;
  final minutes = d.inMinutes.remainder(60);
  final seconds = d.inSeconds.remainder(60);
  return '${hours.toString().padLeft(2,'0')}:'
         '${minutes.toString().padLeft(2,'0')}:'
         '${seconds.toString().padLeft(2,'0')}';
}
```

> **NOTE:** Key concepts we must remember **`inMinutes`** ≠ minutes part, it is total minutes. Always use **`remainder(60)`** for sub-parts
>
> - minutes → **`inMinutes.remainder(60)`**
> - seconds → **`inSeconds.remainder(60)`**

Don’t use Duration:

- For Dates (use **`DateTime()`**)
- Time zones
- Calendar math
