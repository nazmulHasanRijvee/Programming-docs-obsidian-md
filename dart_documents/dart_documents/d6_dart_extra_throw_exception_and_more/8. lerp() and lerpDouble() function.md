Using **`.lerp(…, …, value)`** method based on a value we can interpolate between two numbers. Meaning based on the value (**`progress`**) it will either show the bigger padding size or smaller padding size. Like smart switching based on a value.

We can also use **`lerpDouble(…, …, value)`** function to interpolate between two numbers using a value like it will return the big number or small number based on **`progress`**

```dart
padding: EdgeInsets.lerp(
          const EdgeInsets.all(24),
          const EdgeInsets.all(12),
          progress,
        )!,

        child: Column(
          // …
          AnimatedDefaultTextStyle(
             // …
             style: TextStyle(
               fontSize: lerpDouble(30, 18, progress)!,
               // …
             ),
             child: const Text('৳ 2,450.00'),
```
