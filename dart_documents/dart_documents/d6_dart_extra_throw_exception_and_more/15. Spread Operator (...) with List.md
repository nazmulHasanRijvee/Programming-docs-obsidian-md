We can copy a **List** to another **List** using spread operator (**`…`**) without worrying about pointing to the same memory address (DSA problem, creates a new memory address)

```dart
final List<int> list1 = [1, 2, 3, 4];
final copiedList = [...list1];
print(copiedList);
```

---
## Spread_Operator_with_.map()_and_List.generate()

Also use Spread Operator (**`…`**) to unpack or insert all elements from one **List** (or collection) directly in a **Map** or **List** (another collection) with additional operations (like **`.map()`** method)

```dart
final List<int> list1 = [1, 2, 3, 4];

final list2 = [
  ...list1.map((e) => e +1).toList()
];

print(list2);
```

Or using **`List.generate(…)`** method, we can also add new elements (5, 6) at the last

```dart
final list2 = [...List.generate(…), 5, 6];

print(list2);
```

## In_Flutter

In **Flutter** Spread Operator (**`…`**) can be used to past or unpack a **`List<Widget>`** (usually generated by **`List.generate(…)`**) in **`children:`** properties **`[]`** list

```dart
// ...
children: [
  const Header(),
  
  ...menuItems,
  
  const Footer()
]

List<Widget> menuItems() {
  Return List.generate(3, (int index) => …)
}
```

---
## Null-aware_Spread_Operator

By using Null-aware Spread Operator (**`…?`**) we can SAFELY skip the **`List<Widget>?`** if its **`null`**. Meaning if there is element in the **List** unpack it otherwise ignore it

```dart
List<int>? list1 = null;

List<int> list2 = […?list1, 5, 6]

Print(list2); // [5, 6]

// In Flutter

// …

children: [
   const Header(),

   …?menuItems, // if null skip it

   const Footer()
]
```
