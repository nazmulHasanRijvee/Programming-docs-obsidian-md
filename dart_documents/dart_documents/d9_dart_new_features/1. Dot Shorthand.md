## Dot_Short-Hands_for_enum

**Dart 3.10** introduced “contextual shorthand” for **`enum`** values inside **Flutter** widget properties. When a parameter expects an **`enum`** type like this **`crossAxisAlignment: CrossAxisAlignment.center`** **Dart** already knows the type. So instead of repeating **`CrossAxisAlignment.start`** we can simply write **`.start`**

Old way:

```dart
Row(
  crossAxisAlignment: CrossAxisAlignment.start,
)
```

New dart dot shorthand:

```dart
Row(
  crossAxisAlignment: CrossAxisAlignment.start,
)
```

Works with many **`enum`**’s in **Flutter**:

- **Alignment** → **`alignment: .center,`**
- **TextAlign** → **`textAlign: .right`**,
- **MainAxisAlignment** → `mainAxisAlignment: .spaceBetween,`
- **BoxFit** → `fit: .cover,`
- **Axis** → `scrollDirection: .horizontal,`
- **BlendMode** → `colorBlendMode: .multiply,`

> **NOTE:** **Dart** chooses shorthand automatically based on context. Dot shorthand for **`this`**:

**`.title`** ≡ **`this.title`**

Dot shorthand for `enum`'s:

**`.start`** ≡ **`CrossAxisAlignment.start`**

## Dot_Shorthand_with_this

Normally, inside a class, when we want to access a variable from the same class, we must write like this **`this.name`**, **`this.age`** and **`this.calculateBMI()`**. But Dart 3.10 lets us write a short form like this **`.name`**, **`.age`** and **`.calculateBMI()`**. Yes, just a dot. Dart automatically understands it means **`this.name`**, **`this.age`** and **`this.calculateBMI()`** in that class

Example old way

```dart
class Person {
  final String name;
  final int age;
  Person(this.name, this.age);
  void printInfo() {
    print(this.name);
    print(this.age);
  }
}
```

New version using dot shorthand

```dart
class Person {
  final String name;
  final int age;
  Person(this.name, this.age);
  void printInfo() {
    print(.name);  // same as print(this.name)
    print(.age);   // same as print(this.age)
  }
}
```

We can also use it in Flutter build methods. Before **`Text(this.title)`** but now **`Text(.title)`**

```dart
class MyWidget extends StatelessWidget {
  final String title;
  const MyWidget({required .title});

  @override
  Widget build(BuildContext context) {
    return Text(.title); // instead of this.title
  }
}
```

We can also use them in methods and constructors (before **`double bmi = this.calculateBMI()`** and **`User({required this.name, required this.age})`** ). Now

```dart
double bmi = .calculateBMI();
User({required .name, required .age});
```

Note: It works only inside a class. We can only use .name when “name” is a field or method of this object. The leading dot always means “**`this`**” according to context. We can use it in methods, constructors, getters/setters, Flutter **`build()`** methods and overrides.

## Dot_Shorthand_For_Creating_Objects

We can use dot shorthand’s for creating objects using **`.new()`** keyword, we just need to specify the class as Type

Old

```dart
final controller = TextEditingController(text: …);
```

New way

```dart
final TextEditingController controller = .new(text: 'LOl');
```
