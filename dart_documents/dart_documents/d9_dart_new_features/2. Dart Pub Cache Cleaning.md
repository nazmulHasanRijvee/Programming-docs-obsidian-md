**`dart pub cache gc`** command cleans our local Dart/Flutter package cache by removing unused packages. It basically means smart cleanup of unused dependencies without breaking active projects

---
## Understand_the_System

When we run:

```bash
flutter pub get
```

Or:

```bash
dart pub get
```

**Dart** downloads package’s and stores them in a global cache folder. Example locations:

- Linux/macOS → `~/.pub-cache`
- Windows → `%LOCALAPPDATA%/Pub/Cache`

This cache is shared across ALL our projects. So, if we use http package in 10 projects → it downloads only once

---
## What_it_does

Think of it like Garbage Collector (GC) in memory but for packages. Internally:

- It scans our projects
- Finds which packages are still used
- Marks them as ✅ "alive"
- Deletes everything else ❌

---
## Usage

Run it in terminal / command line. Anywhere works:

```bash
dart pub cache gc
```

Or (Flutter projects also fine):

```bash
flutter pub cache gc
```

Then run

```bash
flutter clean
flutter pub get
```

---
## Use_Cases

- Disk space getting full. Big win (can free GBs)
- After working on many projects. Especially if we experiment a lot
- Weird dependency issues. Sometimes old cached packages cause bugs
- Before CI/CD or cleanup. Keeps environment clean

## Mental_Model_(Remember_this)

Think of it like:

| Concept | Real life |
| --- | --- |
| Pub cache | Warehouse |
| Packages | Items |
| Your projects | Customers |
| gc | Throw away items nobody uses |

---
## Comparison_with_Other_Commands

| Command          | What it does                              |
| ---------------- | ----------------------------------------- |
| pub get          | Download dependencies for current project |
| pub upgrade      | Get newer versions                        |
| pub cache repair | Reinstall ALL cached packages             |
| pub cache clean  | Delete EVERYTHING                         |
| pub cache gc     | Delete ONLY unused packages ✅             |
