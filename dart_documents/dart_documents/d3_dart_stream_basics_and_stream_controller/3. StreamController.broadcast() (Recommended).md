**`StreamController<T>.broadcast()`** constructor creates a controller where the **Stream** can be listened to more than once. It returns a Broadcast **Stream**.

A Broadcast **Stream** do not buffer events when there is no listener:

- Meaning its inert until a subscriber starts listening on it (using the `onListen: () {}` callback to start producing events)
- Ensuring it does not leak resources (like **WebSocket's**) when no user ever listens to the **Stream**
- Which can have multiple listeners/subscribers (Used in template)

```dart
Future<void> produceEvents(StreamController<int> controller) async {
  for (var i in [0, 1, 2]) {
    await Future.delayed(const Duration(milliseconds: 500));
    controller.add(i);
  }
  
  await controller.close();
}

void main() async {
  late final StreamController<int> controller;
  
  controller = StreamController<int>.broadcast(
    onListen: () {
      produceEvents(controller);
    },
  );

  // .listen() can be used too
  await for (final value in controller.stream) {
    print(value);
  }
}
```

**`.broadcast()`** itself does not automatically make our producer lazy. If we call **`controller.add(…)`** instead, production starts regardless of whether a listener exists or not.

Another use case is needing multiple listeners of a **Stream** (using normal **Stream** throws **StateError**) where multiple parts of an application may need to listen to it simultaneously.
