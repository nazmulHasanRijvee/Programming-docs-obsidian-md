Mental model first, **`Future`** = One value. A **`Future<T>`** delivers one result for one request and then finishes. Example:

```text
Request ─────► Response ✔
```

A **Stream** delivers multiple values over time. Think of it as YouTube Live stream. Data keeps arriving until the **Stream** closes. Examples:

- Chat messages
- GPS location updates
- Sensor data
- **Firebase Firestore** snapshots
- WebSocket messages

```text
1 ──► 2 ──► 3 ──► 4 ──► Done
```

---
## Listening_to_a_Stream

Instead of **`await`**, we listen (using **`.listen()`**). Whenever new data arrives, the callback runs.

We use **`.listen((…) {…})`** method to listen for the values and each new value (data) is given internally and which returns a **`StreamSubscription<T>`** for cancelling the listener.

**IMPORTANT**, make sure to cancel or dispose a **Stream** using **`.cancel()`** method, after listening to it is done otherwise it can cause Memory Leak.

```dart
stream.listen((data) {
  print(data);
});

stream.cancel();
```

## Creating_a_Stream

The simplest way to create a **Stream** is define a method of **`Stream<T>`** type that will return a **Stream**.

**`async*`** instead of **`async`**. **`async*`** means “This function produces a stream of values over time”.

- **`async`** → returns one **`Future`**
- **`async*`** → returns many values as a **Stream**

`yield` instead of `return` in the method that returns a **Stream**. There’s `yield*` too, which means “yield everything from another stream”.

- `yield` value → emit one event
- `yield*` stream → emit all events from another stream

```dart
Stream<int> numbers() async* {
  yield 1;
  yield 2;
  yield 3;
}
Stream<int> allNumbers() async* {
  yield 0;
  yield* numbers();
  yield 4;
}
```

Usage, listen to the **Stream** using `.listen()` method or to read every value from the **Stream** use `await for` loop (SEE [awai for](#Reading_Every_Value_of_a_Stream_Sequentially(await_for))).

```dart
allNumbers().listen((data) {
  print(data);
});
/// Or
await for (final n in numbers()) { // yield* is the short for this
  print(n);
}
```

Output:

```text
0
1
2
3
4
```

## Reading_Every_Value_of_a_Stream_Sequentially(await_for)

Assigning a `Stream<T>` function (`myFunction`) to a variable and using `.listen()` method to listen to it. Then calling `.cancel()` immediately cancels the **StreamSubscription** before any value from the **Stream** can be consumed (async scheduling problem).

```dart
Stream<int> myFunction() async* {
  for(final value in [1, 2, 3,]) {
    yield value;
  }
}

void main() {
  final stream = myFunction();
  
  final subscription = stream.listen((value) {
    print(value);
  });
  
  subscription.cancel(); // cancelled right away
}
```

To read every value from this **Stream** sequentially, use asynchronous for loop (`await for`) which iterates over the events of a **Stream** like a `for` loop.

The `await` keyword ensures all values are read from that **Stream** and resource disposal or cleanup is automatic when loop is completed or exited (no `.cancel()` needed).

When the **Stream** ends the `await for` loop ends too.

```dart
void main() async {
  final stream = myFunction();
  
  await for (final value in stream) {
    print(value);
  }
}
```

## break_in_await_for

`break` exits the loop and cancels the underlying stream subscription. Useful when we want to stop listening before the **Stream** naturally ends.

```dart
// …
await for (final position in locationStream) {
  if (position.isDestination) {
    break; // unsubscribes and exits
  }
}
```
