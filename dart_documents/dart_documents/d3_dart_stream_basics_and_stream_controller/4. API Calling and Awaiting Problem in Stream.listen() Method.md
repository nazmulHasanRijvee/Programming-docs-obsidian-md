## The_Problem

The Problem, if we are calling an API using a **Stream** value of **`StreamSubscription<T>`** in **Stream.listen()** inside a method then that method won’t wait for the API call to complete it, simply starts the **Stream** and finishes or returns. Because **Stream.listen()** is not a **Future** which can be awaited (one request, one response), it’s a **`StreamSubscription<T>`**.

Also `await` can’t be added before **Stream.listen()** (Because its **`StreamSubscription<T>`** not **`Future<StreamS…>`**) and even if we do tight coupling and return a `bool` value from **`_handleAuthDeepLink()`** method it won’t simply work because **`Stream.listen()`** can’t be awaited (sync vs async problems or race conditions) and `bool` value (**`isSuccess`**) will always be **false** (**return** **`isSuccess`** in **startAuth** runs before the `isSuccess` from handler method is returned).

---
## The_Solution

Instead use **`Completer<T>()`** pattern to control the **`startAuth()`** method so it only finishes when API calling is finished in the **`_handleAuthDeepLink()`** method.

**`Completer<bool>()`** (which determines when **`startAuth`** finishes or returns a `bool` value based on API success) because here **Stream.listen()** is used here. So, **`startAuth`** doesn’t wait for calling the authentication API because we can’t **await** a **Stream.listen()** method (In the UI **`startAuth`** doesn’t wait for the API call and see if it succeeded or not, it launches the URL in browser and finishes immediately).

**`Completer<bool>()`** handles what to return **true**/**false** for **await** **`startAuth`**’s (`Future<bool>`) based on the API call success in **`_handleAuthDeepLink()`** using **`_completeAuth()`** helper method.

Define a **`_completeAuth()`** helper method to finish the **`startAuth`** with a `bool` value (based on API call success) using **`_authCompleter?.complete(…)`**. Also check for null safety, if completer is not **null** and not completed, only then complete it.

Lastly define another **`_stopAuth()`** helper method to stop the loading (`state = false`), cleanup the **Stream** or cancel it and set it to **null** after API is called and authentication succeeded or failed.

> **IMPORTANT:** Call **`_stopAuth()`** method before completing with the result (**`_completeAuth`**) to clean up the **Stream** and stop the loading state before **`startAuth()`** method finishes (to prevent unnecessary **async** race conditions like method completes before stopping the loading and cleaning up the **Stream**).

**AuthNotifier** Class:

```dart
class AuthNotifier extends Notifier<bool> {  
  // Dependency injection
  DeepLinkService get deepLinkService =>
      ref.read(deepLinkProvider);
  ApiService get apiService => ref.read(apiServiceProvider);
  
  StreamSubscription<Uri>? streamSubscription;
  Completer<bool>? _authCompleter;

  @override
  bool build() {
    ref.onDispose(() {
        streamSubscription?.cancel();
    });
    
    return false;
  }

  Future<bool> startAuth(String requestToken) async {
    state = true;
    _authCompleter = Completer<bool>();

    // Prevent duplicate Stream listeners
    await streamSubscription?.cancel();

    streamSubscription = deepLinkService.uriLinkStream
        .listen( (Uri uri) {
          _handleAuthDeepLink(uri);
    });

    /// launch auth Url ...

    final initialUri = await deepLinkService.initialUriLink;
    if(initialUri != null) {
      _handleAuthDeepLink(initialUri);
    }

    return _authCompleter!.future;
  }

  Future<void> _handleAuthDeepLink(Uri uri) async {
    if(uri.host != 'auth') return;

    final approved =
    uri.queryParameters['approved'];

    final requestToken =
    uri.queryParameters['request_token'];

    if (approved != 'true' || requestToken == null) {
      await _stopAuth();
      _completeAuth(false);
      return;
    }

    final response = await apiService.getRequest(url: '...');
    if(response.isSuccess) {
      // Save session id to auth controller
    }

    await _stopAuth();
    _completeAuth(response.isSuccess);
  }

  Future<void> _stopAuth() async {
    state = false;
    // Stop listening, clean up Stream to prevent memory leak
    await streamSubscription?.cancel();
    streamSubscription = null;
  }

  void _completeAuth(bool success) {
    // if completer is not null and not completed, then complete it
    if (!(_authCompleter?.isCompleted ?? true)) {
      _authCompleter?.complete(success);
    }
  }
}
```

In the UI, just **await `startAuth()`** which gives a **bool** value to know if the API succeeded or not:

```dart
…
final state = ref.watch(authProvider);
final isSuccess = await ref.read(authProvider).startAuth(…);
if (isSuccess) {
    // Navigate to Home Screen
}
```
