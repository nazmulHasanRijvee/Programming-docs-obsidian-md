Every **`Future<T>`** method or class has **`.timeOut()`** method property in them.

We can use it to set a time out so users don’t have to wait for a long time if API response or **`Future`** result is taking more time than it should (Best Practice for **`Future`**’s)

**`.timeOut()`** method takes two parameters:

- **`const Duration()`** to specify the duration for time out
- **`onTimeout:`** void callback method is triggered when time runs out and **Future** still doesn’t give any result

```dart
Future<void> timer() async {
  await Future.delayed(const Duration(seconds: 3));

  print('Done');

}

void main () async {
  timer().timeout(
    const Duration(seconds: 2),
    onTimeout: () {
      print('timed out');  // shows timed out
    }
  );
}
```
