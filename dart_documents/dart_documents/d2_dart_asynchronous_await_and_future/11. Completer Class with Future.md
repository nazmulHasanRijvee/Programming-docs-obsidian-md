**`Completer<T>()`** is a way to control **`Future<T>`** objects and to complete them later with a value or error. Think of **Completer** as a remote control and **Future** is like a TV. A **Completer** gives us the remote control to decide when the **Future** finishes (or returns)

---
## The_Problem_Completer_Solves

Normally, an **`async`** function finishes when it reaches its end. Like:

```text
Call getName()
↓
wait 2 sec
↓
return "Nazmul"
```

The function itself knows when it is finished

```dart
Future<String> getName() async {
  await Future.delayed(Duration(seconds: 2));
  return "Nazmul";
}
```

But what if the function doesn't know when it will finish. Example:

```text
Show Dialog
↓
User thinks...
↓
User clicks OK
↓
Return result
```

The function has no idea whether the user will click in 2 seconds, 20 seconds or 2 hours. The completion depends on someone else. That's exactly what **`Completer<T>()`** is for. (It can also solve API calling and awaiting problem in **`Stream.listen()`**)

> **NOTE:** Basically, solves async race conditions

---
## Basic_Usage

Here, the **`Future<String>`** (**`future()`**) is read only, the **Completer** controls it. First create an object of **`Completer<T>()`** using OOP

And return **`_completer.future`** in the method (**`future`**) that we want to control. Value of that **`future`** method will be returned by **`_completer.complete(…)`** method when called

Also check **`_comleter.isCompleted`** to see if **`future`** is already completed or not. We can also complete with error instead of value using **`_completer.completeError(‘…’)`**

```dart
class User {
  final Completer<String> _completer = Completer<String>();
  
  Future<String> future() async {
    return _completer.future;
  }
  
  void complete(String value) {
    if(_completer.isCompleted == false) {
    _completer.complete(value);
    }
  }
  
  void completeWithError() {
    if(_completer.isCompleted == false) {
    _completer.completeError('Error');
    }
  }
}
```

In the UI, **`await future()`** returns ‘**Hello**’ when **`complete(‘Hello’)`** is called

```dart
user.complete(‘Hello’)
…
final value = await user.future() // returns hello
```

---
## Use_Case

Use a **`Completer<T>()`** whenever the completion of a **`Future<T>`** depends on an external event (like API call in **`Stream`**), not on the normal flow of the current function

Solving async race conditions. For example, API calling in **`Stream.listen()`** method and the **`Future<T>`** that started the Stream will only finish API calling is finished in another method. SEE [[]] dart3 streams doc

## Nullable_Completer_for_Fresh_Completer_Per_Method_Call(In_State_Management)

If we directly initialize or create the **Completer** like this:

```dart
final Completer<bool> _authCompleter = Completer<bool>();
// …

Future<void> startAuth() async {
   // …
   return _authCompleter.future;
}
```

Then we’re creating the **Completer** once and the Notifier (state management) get one **Completer** for its entire lifetime. And it creates this problem:

- First Login, everything works -> **`_authCompleter` created** → **User logs in** → **`_authCompleter.complete(true)`**

- Second Login -> **`startAuth()`** → return **`_authCompleter.future`**

But **`_authCompleter.future`** is already completed from the First Login. So, **`await startAuth()`** returns immediately without waiting for the new authentication

The Correct Approach, The **`Completer<bool>?`** should be **`null`** and only initialized when the **`startAuth()`** method is called. So, it represents one authentication attempt, not the lifetime of the Notifier. And every Login gets a fresh **Completer**

```dart
class AuthNotifier extends Notifier<bool> {
  Completer<bool>? _authCompleter;
  // …
  
  Future<void> startAuth() async {
     _authCompleter = Completer<bool>();
     …
     return _authCompleter!.future;
  }
  // …
  
  void complete(String value) {
    if(!(_completer.isCompleted ?? true)) {
    _completer.complete(value);
    }
  }
  
  void completeWithError() {
    if(!(_completer.isCompleted ?? true)) {
    _completer.completeError('Error');
    }
  }
  //…
}
```
