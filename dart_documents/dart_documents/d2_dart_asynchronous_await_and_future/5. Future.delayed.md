**`Future.delayed()`** runs a callback after a specified delay like a timer. It’s just a **`Future`** that completes after some time.

It takes a **`const Duration()`** and a lambda function as void call back that runs after that time. Make sure to **`await`** it

```dart
Future.delayed(const Duration(seconds: 2), () {
  print("Executed after 2 seconds");
});
```

We can also do this

```dart
await Future.delayed(Duration(seconds: 3));
print("Executed after 3 seconds");
```

---
## Common_uses

Show splash screen delay. Waits 3 second then navigates to home screen.

```dart
Future.delayed(Duration(seconds: 3), () {
  Navigator.pushReplacementNamed(context, '/home');
});
```

Simulate network delay in testing

```dart
Future<String> fakeApi() async {
  await Future.delayed(Duration(seconds: 2));
  return "Fetched Data";
}
```

Combine with **`Future.any`** for timeout. If **`fetchWeather()`** is slow, after 3 seconds we’ll get "⚠️ Timeout"

```dart
final result = await Future.any([
  fetchWeather(),
  Future.delayed(Duration(seconds: 3), () => "⚠️ Timeout"),
]);
print(result);
```

> **NOTE:** But use **`http.get().timeout()`** method for this which is better
