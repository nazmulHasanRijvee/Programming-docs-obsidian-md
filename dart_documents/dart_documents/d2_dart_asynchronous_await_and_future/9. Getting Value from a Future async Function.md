**`Future<T>`** type functions can’t return a variable. They return an instance of **`Future`**

> **NOTE:** ONLY if we can't or don’t **`await`** the **`Future<T>`** function

To solve this, define a variable outside the **`Future<void> ... async`** function and then initialize it in the function, lastly use **`setState`** in the function when variable is assigned with value to update the UI with new value.

```dart
 String? cityName;

  Future<void> getCityName() async {
    final String cityName2 = await _weatherService.getCurrentCityName();
    
    setState(() {
      cityName = cityName2;
    });
  }
```

> **NOTE:** Use **`mounted`** after any async operation if there is **`setState`** and anything widget related.
