In **Flutter**, every State object (like our `_WeatherPageState`) has a built-in boolean property called **`mounted`**. It tells whether the State object is still attached to the widget tree.

- **`mounted == true`** → The widget is still active in the UI (visible or in memory).
- **`mounted == false`** → The widget has been disposed (removed from the tree).

```dart
bool get mounted
```

When we call an asynchronous function (like **`await apiCall()`**), **Flutter** might rebuild or dispose of the widget before the function finishes. If our widget was navigated away or disposed while waiting, calling **`setState()`** or showing a **`SnackBar()`** widget using `context` will show an error.

We can safely guard against this by checking if the widget is still mounted after any **`async`** gap:

```dart
_fetchWeather() async {
  String cityName = await _weatherService.getCurrentCity();
  
  if (!mounted) return; // Stop if widget is no longer in tree
  
  try {
    final weather = await _weatherService.getWeather(cityName);
    
    if (!mounted) return; // again safe check before setState()
    
    setState(() {
      _weather = weather;
    });
  } catch (e) {
    if (!mounted) return;
    
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text(e.toString())),
    );
  }
}
```

---
## When_to_use_mounted

Always check `mounted` after any `await` when we plan to:

- Use **`setState()`**
- Use **`BuildContext`** (for navigation, **`SnackBar()`**, dialogs, etc.)
- Access inherited widgets or theme data

---
## context.mounted

We can also use **`context.mounted`** to check if the **`BuildContext`** is active/alive, or if it’s not before using `context` to show a scaffold message or something like that. We can stop that function if **`context`** is not active using `return`

```dart
if(!context.mounted) return;

Navigator.pop(context);
ScaffoldMessenger.of(context).showSnackBar(SnackBar(content: Text(…),));
```

Or we can store the **`context`** in a variable `ctx` before **`await`** or **`async`** call then use that variable. This ensures safe capture before **`await`** (NOT RECOMMENDED)

```dart
Future<void> _moveToNextScreen() async {
  final ctx = context;
  
  await Future.delayed(const Duration(seconds: 2));
  
  if (!mounted) return;
  
  Navigator.pushReplacementNamed(ctx, '/home');
}
```
