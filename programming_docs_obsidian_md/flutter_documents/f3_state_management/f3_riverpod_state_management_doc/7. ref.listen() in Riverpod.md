
\# VERY IMPORTANT, we can use **VoidCallback** and **ValueChanged<…>** or **T Function() name** for this too (But **ref.listen()** is RECOMMENDED for **Riverpod**)

\# **ref.listen()** method registers a function or method that will run every time **state** model is reassigned

\# It also gives us old **state** model and new **state** model (when **state** model is reassigned) as **previous** and **next** internally from **Flutter** which is why **Riverpod** is superior

\# It does not rebuild UI by itself. It just runs our callback. Good for:

- **SnackBars**
- Navigation
- Logging
- Side effects (listening to stream)

\# And **Riverpod** automatically disposes it when widget is destroyed. (no **removeListener()** like Provider). Notifier class:

```dart
class CounterNotifier extends StateNotifier<int> {
  CounterNotifier() : super(0);
  void increment() {
    state++;
  }
}
```

\# Provider:

```dart
final counterProvider = StateNotifierProvider<CounterNotifier, int>((ref) {
  return CounterNotifier();
});
```

\# In UI:

```dart
class _HomePageState extends ConsumerState<HomePage> {
  @override
  void initState() {
    super.initState();
    // Riverpod listener
    ref.listen<int>(counterProvider, (previous, next) {
      if (next == 5) {
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(content: Text("Reached 5!")),
        );
      }
    });
  }
```
