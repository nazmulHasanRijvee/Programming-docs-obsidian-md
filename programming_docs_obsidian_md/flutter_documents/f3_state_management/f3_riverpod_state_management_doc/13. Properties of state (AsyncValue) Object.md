## Basics
\# **state** is an instance of `AsyncValue<List<Song>>` returned by **AsyncNotifier**’s Provider or class, not our data. It can be one of three things:

- `AsyncLoading<List<Song>>`
- `AsyncData<List<Song>>`
- `AsyncError<List<Song>>`

\# Here state has properties like:
- **state.value** -> gives us the data if it exists otherwise gives us the previous data or null (SEE BELOW)

- **state.when()** -> shows different widgets based on the state of **AsyncValue** (data, error, loading)

- **state.whenData()** -> shorthand for **.when()** only to handle ‘data’ case

- **state.hasValue** -> returns **true** when value is set like fetched from the API even if it’s the old value

- **state.hasError** -> returns **true** when error is not **null** meaning **AsyncValue.error()**

- **ref.invalidate** or **ref.refresh** after it least one value or error is emitted

- **state.isReloading** -> returns **true** when the Provider is rebuilt with **ref.watch()** because one of its dependencies changed after at least one value or error is emitted

- **state.isFromCache** -> returns **true** when a value is obtained through offline persistence. It enables the UI to differentiate **state** coming from the database and **state** from the server.

- **state.progress** -> returns the current progress of the async operation. This value will be between **0** to **1**. By default, progress is **null** but notifiers can set this manually like this:

```dart
state = AsyncLoading(progress: 0);

await something();

ref.state = AsyncLoading(progress: 1);
```

- **state.isLoading** -> returns **true** when some new value is currently asynchronously loading (**progress** is not **null**)

\# **state.isLoading** can be used as an alternative of **.when()** method to show a loading spinner

```dart
// …

@override

  Widget build(BuildContext context, WidgetRef ref) {

    final state = ref.watch(favouriteSongsProvider);

    final isLoading = state.isLoading;

    return isLoading ? CircularProgressIndicator() : Placeholder();

  }
```


> **NOTE:** **ref.listen()** can be used too for side effects like showing a **SnackBar()** widget when error

## state.value_(getting_previous_data)
\# We can access the **state** of `AsycnNotifier<T>` class anywhere in the UI using **ref** for **ProviderScope()** or **container** for **ProviderContainer()** (testing). This is the Provider instance or object of the `AsyncNotifier<T>` class

```dart
final state = ref.read(taskAsyncProvider);  // AsyncLoading /…

// for testing using Provider Container
final state = container.read(taskAsyncProvider)
```

\# Then we can access the value or data using **state.value**

\# **state.value** is a getter on **AsyncValue** which says “Give me the data if it exists, otherwise give me the previous data or null”.

\# But **state.value** can be **null** if this is the very first load and there’s no previous value (or data). Or accessing **state.value** after calling **ref.watch(provider).unwrapPrevious()** (clears previous data) than it will return **null** too

\# Its behavior looks like:

| Current State          | value                               |
| ---------------------- | ----------------------------------- |
| **AsyncLoading()**     | Previous **List<song>** or **null** |
| **AsyncError()**       | Previous **List<song>** or **null** |
| **AsyncData([songs])** | Current or new **List<Song>**       |

\# Mental model. The **.value** getter returns the value currently exposed, which may be:

- the current successful value **(AsyncData**)
- the previous value while loading or after an error
- **null** if no value has ever been available

```text
AsyncValue<List<Song>>
├── Current state
├── Current value (if any)
└── Previous value (optional)
```

\# Basically, we can get existing data (`List<Song>` from the previous API call) in the manual method we define in the **SongsNotifier** class, if data exists otherwise just assign empty **List []** using **null** safety

```dart
class SongsNotifier extends AsyncNotifier<List<Song>> {

  @override
  Future<List<Song>> build() async {
    final repo = ref.watch(songRepositoryProvider);

    return repo.getSongs();
  }

  Future<void> toggleFavourite(Song song) async {
    final current = state.valueOrNull ?? [];

    final isFavourited = current.any((s) => s.title == song.title);

    if (isFavourited) {
      state = AsyncData(current.where((s) => s.title != song.title).toList());
      return;
    }

    final favouriteRepo = ref.read(favouriteRepositoryProvider);
    final success = await favouriteRepo.addFavourite(song.title);
    if (!success) return; // persistence failed, leave state untouched
    state = AsyncData([...current, song]);
  }
}

final favouriteSongsProvider =
    AsyncNotifierProvider<FavouriteSongsNotifier, List<Song>>(
  SongsNotifier.new,
);
```

## state.value_in_UI
\# Also use the **AsyncNotifier**’s Provider instance (or **state**) using **state.value** in UI without using the **.when()** method. This is helpful when we just a need a simple value and don’t need to show different widgets in **loading:** , **error:** , **data:**

\# No need to **await** the **ref.watch(…).value** because **state.value** will be return **null** or previous value, or new value based on async call or API call.

\# UI just uses that value, make sure to add safe fallback using null safety (**??**) if needed

```dart
class MyApp extends ConsumerWidget {

  // …
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final themeMode = 
	    ref.watch(themeProvider).value ?? ThemeMode.system; // no await
    
    return MaterialApp.router(
       // …
       themeMode: themeMode,
       // …
    );
}
```
