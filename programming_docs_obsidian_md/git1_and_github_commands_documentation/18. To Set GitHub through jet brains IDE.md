Open a project in **IntelliJ IDEA**. Go to menu: VCS and Enable Version Control Integration... Then choose Git and click OK. Local repository is created like **`git init`**. IntelliJ will create the **`.git`** folder and start tracking files.

Create **`.gitignore`** (optional but recommended): Right-click project → New → File → name it **`.gitignore`** and add patterns.

Commit our files: Open the Commit tool window (bottom) or press **`Ctrl+K`**. Select files to include, write commit message (e.g. “Initial commit”), then Commit.

Before adding remote repo make sure to rename local repo branch from “master” to “main”.

Add remote repo to local repo. Go to Git then go to Manage Remotes... Click the + icon. Enter Name: origin URL: paste our GitHub repo link (**`https://github.com/username/repo.git`** or SSH URL). Press OK. Then push: Git → Push (**`Ctrl+Shift+K`**). IntelliJ will ask us to set upstream; choose origin/main.

If file already exists pull it and choose merge conflicts use this command in the terminal to pull --rebase.

```bash
git pull origin main --rebase
```

If we want to delete everything that doesn’t matter just force push it will clear everything that was present in the remote repo.

```bash
git push origin main --force
```

Do this in Ide instead of terminal. Pull with Rebase in IntelliJ. Go to top menu → Git → Pull… In the dialog: Make sure Remote = origin, Branch = main. Check the box “Rebase” (instead of merge). Click Pull. IntelliJ will fetch remote commits and rebase our local ones on top. Then go to Git → Push… (or **`Ctrl+Shift+K`**) and push normally.

Force Push in IntelliJ. If we decide to overwrite the remote: Go to Git → Push… (**`Ctrl+Shift+K`**). In the Push dialog, click the small gear ⚙️ icon (top right). Select Force Push. Confirm when IntelliJ warns us. This will overwrite the remote branch with our local one.
