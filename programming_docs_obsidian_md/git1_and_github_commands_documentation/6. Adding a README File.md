First create a **`README.md`** file with text editor or something else in the local repository folder where git is initialized. We might need to rename it to **`README.md.text`** to **`README.md`**, enable file extension in the view of file explorer.

```bash
git add README.md
```

This tells the git to watch the new file README.md

```bash
git commit -m "Add README.md"
```

This command stages the file for upload with a comment.

```bash
git push origin main /(or)            git push
```

This uploads the **`README.md`** file to GitHub remote repository.

---
## README_Structure(Recommended)

A great README answers: What is this? Why should I care? How do I run it?

```markdown
# Project Name

## 🚀 Features
## 🛠 Tech Stack
## 📦 Installation
## ▶️ Usage
## 🧪 Testing
## 📸 Screenshots
## 🤝 Contributing
## 📄 License
```

---
## Headings_in_README

We can add headings like title, section, subsection and more using #, ##, ### and more

```markdown
# H1 – Project Title
## H2 – Section
### H3 – Subsection
#### H4
##### H5
###### H6
```

## Text_Styling_in_README

We can make the text bold by writing in a double star pair (**\*\*text\*\**)

Italic by writing the text in a single star pair (**\*text\**)

And we can mix bold + italic by writing the text in triple star pair (**\*\*\*text\*\*\**)

We can make the text strike through using **`~~…~~`**

And inline code using single back tics pair **``**

```markdown
**Bold**
*Italic*
***Bold + Italic***
~~Strikethrough~~
`Inline code`
```

## Paragraphs_and_Line_Breaks

We need to add extra enter between two lines to go to new line

```text
This is a paragraph.

This is a new paragraph.
```

Or we can enter two spaces after the first line to go to new line

```text
Line one  # Two extra spaces
Line two  
```

---
## Lists_in_README

We can make unordered list just using hyphen **`-`** and tab

```markdown
- Item
- Item
  - Subitem
    - Sub-subitem
```

For ordered list just use numbers **`1.`**, **`2.`** …

```markdown
1. First
2. Second
3. Third
```

For task lists use hyphen **`-`**, third parentheses **`[]`** and **`x`**

```markdown
- [x] Done
- [ ] Not done
```

---
## Links_in_README

We can add links to words, when that word is clicked the user will be redirected to that link. We can do this by writing the word in third parentheses **`[]`** and link in the first parentheses **`()`**

```markdown
[GitHub](https://github.com)
```

Or we can add the link directly

```markdown
https://github.com
```

---
## Images_in_README

We can simply drop and drop the image in README editor. Or we can add manually using **`![alt text](image-url)`**

```markdown
![Alt text](image-url)
```

Image with link, when tapped will be redirected to link:

```markdown
[![Logo](image-url)](https://link.com)
```

---
## Code_Blocks_in_README

For in line code use single back ticks pair **``**

```markdown
Use `print()` to log
```

For multi-line or code block (like a code snippet) use triple back tics and write the programming language name (Supported language **`dart`**, **`js`**, **`ts`**, **`python`**, **`java`**, **`bash`**, **`json`**, **`yaml`**, etc.)

```python
var = 'hello'
print(var)
```

```bash
flutter pub get
```

## Blockquotes_in_README

We can use is single right arrow **`>`** for quote and double right arrow for nested quote **`>>`**

```markdown
> This is a quote
>> Nested quote
```

## Tables_in_README

We need to follow this pattern for tables:

```markdown

|--------|--------|
| Login | ✅ |
| Map | ❌ |
```

Alignment using colon **`:`**

```markdown
| Left | Center | Right |
|:---- |:------:| -----:|
|      |        |       |
```
