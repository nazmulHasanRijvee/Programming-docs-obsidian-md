Shows the status of your files like tracked, untracked, modified.

```bash
git status
```

> **NOTE:** We can run multiple commands at once using && like this:

```bash
git add . && git commit -m “…”
```

---
## Updating

For later changes or updating it.

```bash
git add .
git commit -m “Update message”
git push
```

---
## Check_commits

```bash
git log
git log --online // More tidy
```

To check out commit logs, what happened.

```bash
git checkout commit_hash              // to get in
git checkout main                     // to get out
```

To check a commit in detail and get out of it.

---
## Undo_Commits

To get back a deleted file. Press **`i`** to edit the commit message. After edit, press **`Esc`** and **`;`**, **`w`**, **`q`** to save and exit.

```bash
git revert commit_hash
```

To wipe the slate clean. Get back to that hash. It wipes the history.

## More_Basics

To view the branches:
