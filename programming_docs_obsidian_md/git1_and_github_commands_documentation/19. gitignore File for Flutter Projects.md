##### 1. General junk files

- `*.class`, `*.pyc` → compiled files from Java/Python, not needed in repo.
- `*.log`, `.buildlog/` → logs are temporary.
- `.DS_Store` (macOS), `.atom/` (editor settings), `.history`, `.svn/` (old SVN folders).
- `.swiftpm/` (Swift package manager cache).

```gitignore
*.class
*.log
*.pyc
*.swp
.DS_Store
.atom/**
.build/**
.buildlog/**
.history
.svn/**
.swiftpm/**
migrate_working_dir/**
```

##### 2. IDE-related(don’t_version_your_personal_editor_settings)

- IntelliJ/Android Studio: `.idea/`, `*.iml` = local configs.
- `.vscode/` → commented out by default, because sometimes teams share launch configs.

```gitignore
*.iml
*.ipr
*.iws
.idea/**
#.vscode/**
```

##### 3. Flutter/Dart/Pub

- `.dart_tool/`, `.flutter-plugins*`, `.packages`, `.pub/`, `.pub-cache/` → build + package resolution files, auto-generated.
- `/build/` → generated build outputs (per platform).
- `coverage/` → test coverage reports.
- `generated_plugin_registrant.dart` → auto-generated plugin bindings.

```gitignore
**/doc/api/**
.dart_tool/**
.flutter-plugins
.flutter-plugins-dependencies
.packages
.pub-cache/**
.pub/**
build/**
coverage/**
generated_plugin_registrant.dart
```

##### 4.iOS-specific

- `.last_build_id` → auto-generated hash for builds.
- `Flutter.framework`, `Flutter.podspec` → generated by Flutter build.
- `Pods/` & `.symlinks/` → CocoaPods packages.
- `GeneratedPluginRegistrant.*` → regenerated each build.
- `DerivedData/` → Xcode temporary folder.

```gitignore
**/ios/Flutter/.last_build_id
ios/Flutter/Flutter.framework
ios/Flutter/Flutter.podspec
ios/.symlinks/**
ios/Pods/**
ios/Runner/GeneratedPluginRegistrant.***
ios/ServiceDefinitions.json
DerivedData/**
```

##### 5.macOS-specific

Same logic as iOS, these files regenerate automatically.

```gitignore
macos/Flutter/GeneratedPluginRegistrant.swift
macos/Pods/**
macos/Runner/GeneratedPluginRegistrant.***
```

##### 6. Android-specific

- `local.properties` → stores SDK path (different for each developer).
- `gradle-wrapper.jar`, `.gradle/`, `gradlew`, `gradlew.bat` → environment-specific, regenerated.
- `key.properties`, `*.keystore`, `*.jks` → SECRET signing keys (must never be pushed).
- `release/`, `profile/`, `debug/` → build outputs.
- `google-services.json` → contains Firebase credentials (secret).

```gitignore
/local.properties
**/android/**/gradle-wrapper.jar
**/android/.gradle/**
**/android/captures/**
**/android/gradlew
**/android/gradlew.bat
**/android/key.properties
**/android/app/*.keystore
**/android/app/*.jks
**/android/app/release
**/android/app/profile
**/android/app/debug
**/android/app/google-services.json
```

##### 7. Windows-specific

Auto-generated plugin registrant for Windows builds.

```gitignore
windows/flutter/generated_plugin_registrant.cc
```

##### 8. Linux-specific

Same, for Linux builds.

```gitignore
linux/flutter/generated_plugin_registrant.cc
```

##### 9. Web-specific

Temporary build artifacts for Flutter Web.

```gitignore
web/.dart_tool/**
```

##### 10. Obfuscation_+_Symbolication

- `app.*.map.json` → generated if you enable obfuscation.
- `app.*.symbols` → generated for debugging/symbolication.

```gitignore
app.*.map.json
app.*.symbols
```

With this **`.gitignore`**, our repo will only contain source code + config (the stuff you actually need), while ignoring generated files, secrets, and local junk.
