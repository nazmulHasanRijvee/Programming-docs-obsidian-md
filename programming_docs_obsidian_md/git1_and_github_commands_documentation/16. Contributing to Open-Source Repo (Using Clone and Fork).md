We can contribute to open-source repositories using clone and fork

---
## Problem

If we ONLY **`clone`** a repo then

```bash
git clone <repo-url>
```

This copies repo to our local machine. We can edit and commit locally

But when we try to do

```bash
git push
```

We can’t push to the original repo, unless we’re a collaborator because it’s not our repo

So, cloning alone won’t do it

---
## Correct_Industry_Workflow_(Fork_+_Clone_+_PR)

**Step-1**, fork the **repo** (on **Github**):

- Click Fork
- Now we have:

  ```text
  Original repo (owner)
       ↓
  Your fork (your GitHub account)
  ```

**Step-2**, **clone** your fork

```bash
git clone https://github.com/your-username/repo-name.git
cd repo-name
```

**Step-3**, Add original repo as upstream (important and for more info see below **origin** vs **upstream**). So, we’ll have:

- **`origin`** → our fork
- **`upstream`** → original repo

```bash
git remote add upstream https://github.com/original-owner/repo-name.git
```

**Step-4**, Create a new branch (best practice)

```bash
git checkout -b feature-branch
```

**Step-5**, Make changes and commit

```bash
git add .
git commit -m "Added new feature"
```

**Step-6**, Push to our **fork**. This works because it’s our repo

```bash
git push origin feature-branch
```

**Step-7**, Create Pull Request (PR):

- Go to your fork on **Github**
- Click “**Compare & pull request**”
- Choose:
  - base repo → original repo
  - head repo → your **fork**

Now we’re requesting “Please merge my changes into your repo”

**Step-8**, Maintainer reviews + merges. They may:

- Accept
- Reject
- Request changes

---
## Keep_Our_Fork_Updated

Use this command:

```bash
git fetch upstream
```

After fetch marge it

```bash
git merge upstream/main
```

---
## Simple_Mental_Model

```text
Original repo (not yours)
       ↑ PR
Your fork (yours)
       ↑ push
Local repo (your machine)
```

---
## Common_Mistakes

“Can I push directly after cloning original repo?”. No, unless we have permission

---
## Summary

- Clone = local copy
- Fork = your own GitHub copy
- Push → goes to your fork
- PR → from your fork → to original repo
