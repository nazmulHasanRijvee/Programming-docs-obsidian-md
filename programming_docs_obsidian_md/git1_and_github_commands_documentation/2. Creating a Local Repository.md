(or **.git** folder) Tells git to watch that project. Initializes git in current project.

```bash
git init
```

Stages file for the next commit. Basically, sends to a waiting area.

```bash
git add filename  # To add a single file
git add .         # To add all files in the current folder
```

Saves my staged changes with a message. Basically, it’s the save button with a message.

```bash
git commit -m "Your commit message"
```

This command saves repositories address for easy access. Links my local to repository or git to GitHub.

```bash
git remote add origin https://github.com/repository.git
```

Renames current branch to main.

```bash
git branch -M main
```

Pushes code to GitHub. Basically, uploads it.

```bash
git push -u origin main
```

For force pushing the files to the remote repository and deletes everything that was previously in the remote repo.

```bash
git push origin main --force
```

> **NOTE:** When pushing it might say review **TODO**’s, see flutter common issues documentaries for this.
