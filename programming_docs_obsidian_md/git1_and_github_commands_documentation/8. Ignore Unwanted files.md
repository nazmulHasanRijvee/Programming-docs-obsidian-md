**`.gitignore`** tells Git which files/folders not to track. Create a file called **`.gitignore`** in our repo root, then add patterns

Ignore system files

```gitignore
.DS_Store
Thumbs.db
```

Ignore build files

```gitignore
/build
/node_modules
```

Ignore secrets

```gitignore
*.env
```

After updating **`.gitignore`** run this command to remove everything that is now ignored. This will remove all tracked files form gits index only

```bash
git rm -r –cached .
```

Then run **`git add .`** again and git will only add files not listed in **`.gitignore`**

If we want single file to removed run this command to remove from git if already tracked.

```bash
git rm --cached file_name
```
