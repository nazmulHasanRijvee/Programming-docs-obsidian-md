To Create and Switch Branches. Always be in the branch (**`main`**) we want to merge the new branch (**`feat/login`**). Like be in the head of that branch (**`main`**). Create a new branch and switch to it:

```bash
git checkout -b branch_name
```

Or modern command:

```bash
git switch -c branch_name
git switch -c feature/login
```

---
## View_Branches

List of all local branches:

```bash
git branch
```

List local + remote branches. Show which branch we’re on → * marks the current branch

```bash
git branch -a
```

---
## Switch_Between_Branches

```bash
git switch branch_name
```

---
## Merge_Branches

First, switch to the branch we want to merge into (usually **`main`**). If no conflicts → a new commit is created automatically.

```bash
git switch main
```

Then merge another branch into it:

```bash
git merge feature/login
```

---
## Delete_Branches

After merging, we can delete a branch.

Safe delete (warns if not merged)

```bash
git branch -d branch_name
```

Force deletes

```bash
git branch -D branch_name
```

---
## Handling_Merge_Conflicts

If two branches change the same line, we’ll get a conflict. Git will mark the file like this:

```text
<<<<<<< HEAD
code from main
=======
code from feature/login
>>>>>>> feature/login
```

We must manually choose/edit, then:

```bash
git add file_name
git commit
```
