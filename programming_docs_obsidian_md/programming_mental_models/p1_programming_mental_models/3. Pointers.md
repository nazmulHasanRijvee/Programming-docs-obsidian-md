A pointer is a variable that holds address of another variable.

Everything in memory is just memory addresses. When we declare a variable, the computer allocates memory and gives us the address

A pointer (**`&a`** -> 1000) is just us directly working with that address instead or pretending it doesn’t exist. Variables = Labels.

Variables are just convenient labels for memory locations

This clears the concept of pass by reference vs pass by value. When you write code think “What’s happening in memory”.

| Variable Name | a | q | y | m | c | p | r | z |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Memory Address | 1000 | 1004 | 1008 | 1012 | 1016 | 1020 | 1024 | 1028 |

Memory Address:

- **`&a`** -> 1000
- **`&q`** -> 1004
- **`&m`** -> 1012
